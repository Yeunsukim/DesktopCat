secrets.json — 암호화한 비밀 값 
{ "calendar_url": "base64(DPAPI 암호문)", "gemini_key": "…", "gmail_pass": "…", "vt_key": "…" }

값은 win32crypt.CryptProtectData(value.encode("utf-8"), name, None, None, None, 0) 의 결과를 base64 로 적은 것이에요. 같은 윈도우 계정으로만 풀려요(CryptUnprotectData). 빈 문자열을 저장하면 그 키를 지워요. 읽다가 실패하면 빈 문자열(키가 없는 것처럼).

pet_state.json — 키우기 상태 
{"hunger": 48.32, "mood": 47.49, "last_seen": 1792456884.39, "coat": "black"}

0~100 로 잘라서(clamp) 읽어요. 꺼 둔 동안의 변화: elapsed = now − last_seen 일 때 hunger = max(hunger, min(85, hunger + elapsed/300)), mood = max(min(mood, 20), mood − elapsed/300).

icons_backup.json — 바탕화면 아이콘 복원 장부 
{"snap": true,                        // 켜기 전 '격자에 맞추기' 설정 (종료할 때 되돌림)
 "kicked": { "아이콘키": {"origin": [x, y], "final": [x, y]} }}   // 찬 아이콘의 원래 자리와 멈춘 자리

복원할 때 지금 위치가 final 과 6px 넘게 다르면 사용자가 직접 옮긴 것이라 건드리지 않아요. 이전 실행이 갑자기 꺼져 이 파일이 남아 있으면 다음 시작 때 먼저 제자리로 돌려놓아요. 예전 형식("icons" 전체 위치 목록)도 알아봐요.

안전하게 저장하는 법 — 모든 JSON 이 같은 방식

def _atomic_write(path, text):
    tmp = path.with_suffix(path.suffix + ".tmp")
    tmp.write_text(text, encoding="utf-8")   # ① 임시 파일에 다 쓰고
    os.replace(tmp, path)                    # ② 한순간에 바꿔치기: 쓰다 꺼져도 원본은 멀쩡하다
읽기도 같은 철학 파일이 없거나(OSError) 깨졌으면(ValueError) 항상 기본값으로 시작하고 프로그램을 멈추지 않아요. 읽기 실패를 사용자에게 알리지도 않아요(처음 실행과 같은 상태).
