프로그램은 launcher.py 하나로 시작해요. 같은 파일이 옵션에 따라 네 가지 얼굴을 가져요. 설치본에서는 이것이 DesktopCat.exe 이고, 소스로 돌릴 때는 pythonw launcher.py 예요.

시작부터 24fps 루프까지 (단계별)

아래 상자의 번호를 눌러 보세요. cat.main() 의 순서가 그대로예요 — 다시 만들 때도 이 순서를 지키세요(앞 단계의 결과를 뒤 단계가 써요).

launcher.main() → run_guard(extra). 뮤텍스를 만들어 두 번째 지킴이를 막고, Heartbeat()(16바이트 공유 메모리 Local\DesktopCatHeartbeat)를 만든 뒤 subprocess.Popen([exe, "--worker", …], creationflags=CREATE_NO_WINDOW, 표준 입출력 모두 DEVNULL).

cat.main() 첫머리에서 인자(--no-icons --scale --skin --coat --no-autopause --low-priority --quit --worker)를 읽고, 뮤텍스 Local\DesktopCatPetMutex 를 만든다. 이미 있으면(GetLastError()==183) 바로 종료. 종료 이벤트 QUIT_EVENT 도 이때 만든다.

환경 변수 QT_QPA_PLATFORM=windows:fontengine=gdi(글꼴 엔진을 GDI 로: 메모리 약 70MB 절약)는 PyQt 를 불러오기 전에 이미 설정돼 있다. AppUserModelID="DesktopCat.CatSecretary" 를 달아 작업 표시줄이 파이썬 아이콘과 묶지 않게 한다. QApplication 생성(setQuitOnLastWindowClosed(False)) → theme.apply(app, DATA) 로 분홍 스타일시트 적용.

dpr = primaryScreen().devicePixelRatio(), _monitor_layout(app) 로 모니터별 작업 영역(작업 표시줄 제외)과 가상 화면 원점을 구한다. Pet(DATA/"pet_state.json") 을 읽어 꺼 둔 시간만큼 배고픔을 올린다(최대 85).

기본 스킨 sprite 이면 PhotoRig(assets/sprites, 털색, dpr, scale) — sprites.json 을 읽고 33개 동작 폴더가 모두 있는지 확인한다(없으면 예외 → 로그 남기고 뼈대 고양이 CatRig 로 계속). WindowTracker(dpr) 생성.

--no-icons 가 아니면 DesktopIcons(icons_backup.json). attach() 가 성공하면 backup() 으로 현재 아이콘 위치를 저장하고 set_snap(False)(격자 정렬 해제). IconField 가 이를 감싼다. 자동 정렬이 켜져 있으면 아이콘 차기를 끈다.

World(areas, tracker, dpr, 105*scale) → CatBrain(world, pet, field, scale). 사진 고양이는 매달리면 키가 커서 brain.hold_drop = 128*scale.

우클릭 메뉴(밥 주기·놀아주기·한쪽에서 쉬기·고양이 색·앱 등록·앱 지우기·설정·아이콘 차기·아이콘 원래대로·종료)를 만들고 QSystemTrayIcon 에 연결한다. 종료는 cleanup()(pet.save · guard.stop · activity.flush · icons.shutdown) 후 app.quit().

Overlay(고양이 투명 창), LauncherBubble(반원 런처), Balloon(여러 줄 풍선), NoticeWindow(소식 창)를 만들고 모두 tracker.add_ignore(hwnd) — 고양이가 자기 창 위에 올라서지 않게. 8초 뒤 ensure_favicons() 예약.

Settings(DATA), ActivityLog, 작업 함수 5개(calendar·news·yesterday·hourly·gemini_ping)를 Scheduler 에 등록. Routine(settings), scheduler.quiet = routine.is_night. SecurityGuard.start() 로 폴더 감시·점검 스레드 시작.

하트비트(Heartbeat())와 상태 변수를 준비하고 QTimer(PreciseTimer) 를 FRAME_MS=42 로 시작 → app.exec(). 이제부터 frame() 이 24fps 로 불린다. (다음 장)

지킴이 감시 상태 — 눌러서 시험해 보기

지킴이는 2초마다 본체를 살펴요. 아래 버튼으로 네 가지 상황을 재생해 보세요(대기 시간 계산이 코드와 같아요).

지킴이 상태 기계
버튼을 눌러 보세요.
HANG_SECONDS   = 90      # 하트비트가 이 시간 없으면 멈춘 것
STARTUP_GRACE  = 90      # 시작 직후 이만큼은 봐 준다
def _watch(proc, hb, started):
    last_poll, grace_until = time.time(), started + STARTUP_GRACE
    while True:
        rc = proc.poll()
        if rc is not None: return rc
        time.sleep(2.0)
        now = time.time()
        if now - last_poll > 20:          # 우리도 같이 잠들었다 깸 = 절전 복귀
            grace_until = now + 60
        last_poll = now
        if now > grace_until and now - hb.last() > HANG_SECONDS:
            proc.kill(); proc.wait(10); return "hang"

def run_guard(extra):
    # 뮤텍스(이미 있으면 return 0) ... hb = Heartbeat(); fast_fails = 0
    while True:
        started = time.time(); hb.beat()
        proc = subprocess.Popen(child_cmd(extra), creationflags=CREATE_NO_WINDOW,
                                stdin=DEVNULL, stdout=DEVNULL, stderr=DEVNULL)
        rc = _watch(proc, hb, started)
        if rc == EXIT_QUIT: return 0                       # 0 = 사용자가 끔
        if rc == EXIT_RESTART:                             # 3 = 스스로 재시작 요청
            fast_fails = 0; continue
        uptime = time.time() - started
        fast_fails = fast_fails + 1 if uptime < 30 else 0
        wait = 3 if fast_fails <= 1 else min(300, 3 * 2 ** min(fast_fails, 7))
        time.sleep(wait)                                   # 계속 죽어도 포기하지 않는다

종료하는 방법과 종료 순서

정상 종료

메뉴 종료 → cleanup() → app.quit() → main() 이 app.exec() 의 값(0)을 돌려줌 → 지킴이가 EXIT_QUIT 로 보고 함께 끝. 바탕화면 아이콘은 icons.shutdown() 이 원래 자리로 돌려놓고 격자 정렬도 되살린다.

스스로 재시작

자원 점검(60초마다)이나 프레임 오류가 계속되면 ask_restart(이유): 로그에 이유를 남기고 cleanup() 후 app.exit(3). 지킴이는 기다리지 않고 곧바로 다시 띄운다.
