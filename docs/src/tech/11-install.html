빌드, 설치, 삭제

나눠 줄 파일은 DesktopCat_Setup.exe 하나예요. 관리자 권한이 필요 없고(내 계정 폴더에 설치), 설치/삭제 프로그램은 파이썬 없이 돌아가요. 만드는 도구는 build_installer.py 한 파일이에요.

빌드 단계 (python build_installer.py)

build/ 폴더를 지우고 다시 만들어요. 백신이 파일을 붙잡고 있으면 지우기가 실패할 수 있어서 최대 5번(2초 간격) 다시 시도해요.

tools/make_icon.py 가 cute.app_icon_pixmap 을 크기별로 따로 그려서 assets/cat.ico 와 cat_icon.png 를 만들어요(설치 파일·바로가기·시작 메뉴에서 같은 아이콘).

PyInstaller --onedir --windowed --name DesktopCat --icon cat.ico launcher.py. 폴더형이라 켤 때마다 압축을 푸는 시간이 없어요. 자원 포함: --add-data assets/skin, assets/sprites. 보조 프로세스에서만 불러오는 모듈은 자동 분석이 못 찾으므로 --hidden-import 로 명시(calendar_ics gemini_client news_sources activity_log nethelper security sec_* vt_client mail_imap favicon flow routine cute theme win32file win32event …), 라이브러리 자료는 --collect-all icalendar recurring_ical_events x_wr_timezone, --collect-data tzdata, --collect-submodules dateutil. 제외: scipy PIL tkinter matplotlib pytest unittest.

--onefile --windowed --name uninstall installer/uninstall_app.py (numpy·PyQt6 제외). 만들어진 uninstall.exe 를 ①의 폴더 안으로 복사해요 → 설치 폴더에 삭제 프로그램이 함께 들어가요.

쓰지 않는 Qt 파일을 지워요: opengl32sw.dll(소프트웨어 그래픽), Qt6Pdf.dll, imageformats/qpdf.dll, platforms/qminimal.dll, platforms/qoffscreen.dll, plugins/generic, translations. 고양이는 일반 창 그리기만 써요.

① 폴더의 모든 파일을 zipfile.ZIP_LZMA 로 build/payload.zip 에(용량이 가장 작게).

--onefile --windowed --name DesktopCat_Setup installer/setup_app.py + --add-data payload.zip;. --add-data cat.ico;. (numpy·PyQt6·scipy 제외 — 설치 화면은 tkinter). 결과: build/dist/DesktopCat_Setup.exe ← 이것만 나눠 주면 돼요.

개발 중 팁 코드를 고칠 때마다 설치 파일을 다시 만들 필요는 없어요. 개발용 고양이를 재시작하면(python cat.py --quit 후 pythonw launcher.py) 바로 반영돼요. 설치 파일 빌드는 나눠 줄 때만 하세요(몇 분 걸려요).

설치 프로그램이 하는 일 (installer/setup_app.py, ops.py)

실행 중인 고양이 끄기stop_app: 종료 이벤트 → 20초 → taskkill
파일 풀기.installing 폴더에 → 바꿔치기
삭제 정보 등록HKCU Uninstall
자동 실행 등록HKCU Run
바로가기시작 메뉴(·바탕화면)
실행detached
  • 기본 설치 위치 이전에 설치한 곳(레지스트리 InstallLocation)이 있으면 거기, 없으면 %LOCALAPPDATA%\Programs\DesktopCat. 데이터는 %LOCALAPPDATA%\DesktopCat.
  • 중간에 실패해도 이전 설치가 남게: 이름.installing 에 모두 풀고 → 기존 폴더를 이름.old 로 → 새 폴더로 → .old 삭제.
  • 실행 중인지 판단: 뮤텍스 Local\DesktopCatGuardMutex, Local\DesktopCatPetMutex 를 OpenMutexW 로 열어 봐요. 끄기는 request_quit()(이벤트) → 최대 20초 기다림 → 안 꺼지면 taskkill /F /T /IM DesktopCat.exe.
  • 등록하는 것(모두 내 계정, 관리자 권한 불필요)
    • HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\DesktopCat: DisplayName, DisplayVersion(1.0.0), Publisher, InstallLocation, DisplayIcon, UninstallString, QuietUninstallString(--silent), NoModify, NoRepair, EstimatedSize.
    • HKCU\…\CurrentVersion\Run 의 DesktopCat = 실행 파일 경로(선택, 기본 켬) → 윈도우를 켜면 지킴이가 자동 시작.
    • 시작 메뉴 바로가기 데스크탑 고양이.lnk(기본), 바탕화면 바로가기(선택) — PowerShell WScript.Shell COM 으로 만들어요(-EncodedCommand 로 따옴표 문제 회피).
  • 무인 설치: DesktopCat_Setup.exe --silent [--dir 폴더] [--no-shortcut] [--no-startup] [--desktop] [--no-run]. 실패하면 %TEMP%\DesktopCat_setup_error.log 에 스택을 쓰고 종료 코드 1.
  • 설치 후 실행은 DETACHED_PROCESS | CREATE_NEW_PROCESS_GROUP | CREATE_NO_WINDOW 로 설치 프로그램과 분리해요.

삭제 프로그램이 하는 일

  1. (창 모드) "삭제할까요?" → "기록도 함께 지울까요?" (기록 = 배고픔·기분, 설정, 암호화한 키, 활동 기록, 경비 기록·VirusTotal 키). '아니요'면 나중에 다시 설치할 때 이어서 써요. 무인 모드는 --silent (+ --purge 면 기록까지).
  2. 고양이 끄기(바탕화면 아이콘 원위치) → 자동 실행 해제 → 바로가기 삭제 → 숨김 미끼 파일 삭제(remove_canaries: 기록해 둔 것 중 이름에 "고양이미끼"가 든 것만; 기록을 남기는 삭제에서도 항상) → 삭제 정보 등록 해제 → (purge 면 데이터 폴더 삭제).
  3. 실행 중인 자기 자신이 들어 있는 폴더는 못 지우므로, 끝난 뒤에 지우는 배치 파일(rmdir 를 30번까지 반복)을 띄워요.
  4. 마지막 안내는 삭제 프로그램 밖의 작은 별도 프로세스(wscript + 임시 .vbs)로 띄워요. 안내창이 다른 창 뒤에 숨으면 삭제 프로그램이 클릭을 기다리며 끝나지 않는 문제가 있었기 때문이에요(안내창은 항상 맨 앞 플래그).

시험 설치

환경 변수 DESKTOPCAT_APP_ID 를 다른 이름으로 주면 실제 설치와 따로 "(시험)" 이름으로 설치·삭제해 볼 수 있어요(레지스트리 키·바로가기·폴더 이름이 모두 바뀜).
