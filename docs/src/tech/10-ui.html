화면 부품과 디자인 시스템

화면 부품은 두 종류예요. 직접 그리는 투명 창(고양이·풍선·런처)과 Qt 위젯 창(설정·앱 등록·소식·경보·메뉴). 앞쪽은 QPainter 로 모두 직접 그리고, 뒤쪽은 공통 스타일시트(theme.py)로 같은 분위기를 내요.

디자인 토큰

모든 색은 theme.py 와 cute.py 의 상수예요. 문서의 색도 같은 값이에요.

  • 검정 대신 자두색: 글씨·윤곽선은 #5A3A47. 부드럽지만 또렷해요.
  • 모서리는 둥글게(카드 10px, 버튼 15px, 풍선 18px). 윤곽선은 굵게(풍선 2.4px, 카드 1px 분홍).
  • 이모티콘은 화면 글자에서 빼요: 풍선은 cute.strip_emoji, 설정은 버튼·그룹 제목·탭 이름에서 이모지를 지우고 탭에는 직접 그린 아이콘(cute.tab_icon: calendar, news, mail, clock, paw, shield)을 달아요. 고양이가 직접 하는 말(말풍선·시스템 트레이 메시지)에는 이모티콘이 있어도 돼요.
  • QSS 식별자(setObjectName)로 모양을 정해요: page(창 바탕) help(옅은 글) warn ok title card cardtitle stepnum factkey facts primary ghost url fold link. 체크·화살표 그림은 시작할 때 한 번 PNG 로 만들어 데이터 폴더에 둬요(스타일시트는 파일 그림만 받음).

반원 런처의 기하

항목은 반지름 98px 호 위에, 왼쪽 끝(큰 각도)에서 오른쪽 끝으로 고르게 놓여요. 한 쪽에 5개이고, 쪽이 둘 이상이면 양 끝에 화살표가 붙어 항목이 3개씩+화살표 2개가 돼요. 기본 항목 4개(구글 캘린더·Gmail·구글·유튜브)에 내가 등록한 앱이 이어져요.

R_MID=98 BAND=25 ICON=32 PER_PAGE=5 ANG0=12 ANG1=168
각도 = ANG1 − 8 − (ANG1 − ANG0 − 16)·(i/(m−1))

  • 저장 버튼은 창을 닫지 않아요(다른 탭을 계속 볼 수 있게). 저장하면 on_saved() = scheduler.mark_past_done() + apply_mode()(생활 바뀐 것 반영) + guard.reload()(경비 켜기/끄기 반영).

  • "지금 시험"은 먼저 현재 입력값을 저장(_apply())한 뒤 run_test(이름) → 결과가 직접 시험으로 처리돼 즉시 풍선/창으로 보여 줘요.
  • 안내 카드(FoldCard): 제목 + 번호 단계 + 바로가기 링크 버튼 + "사실 표(facts)". 이미 연결돼 있으면 접힌 채로, 아니면 펼쳐진 채로 열려요.
