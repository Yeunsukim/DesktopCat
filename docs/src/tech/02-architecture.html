한눈에 보는 구성도

프로세스는 세 종류예요. 지킴이가 본체를 띄워 지켜보고, 본체는 인터넷·무거운 일이 필요할 때마다 보조 프로세스를 잠깐 띄워요. 그림의 상자를 눌러 보세요.

프로세스 구성도
상자를 눌러 보세요. 선(점선)은 데이터·신호가 흐르는 길이에요.

왜 프로세스를 나눴나

지킴이를 따로

PyQt 같은 큰 라이브러리를 불러오지 않고 표준 라이브러리만 써서 거의 죽을 일이 없어요. 본체가 죽거나 멈추면 되살리는 것이 유일한 일이에요.

보조 프로세스

SSL·캘린더 라이브러리는 불러오기만 해도 메모리를 20~30MB 써요. 몇 초만 살게 하면 끝나는 순간 메모리가 그대로 돌아와요. 키·주소는 표준 입력으로만 받아 프로세스 목록에 안 보여요.

본체 안 스레드

화면 스레드(24fps 타이머) 하나, 그리고 알림 작업·폴더 감시·점검·카메라 감시 같은 작업 스레드가 있어요. 작업 스레드의 결과는 Qt 신호로만 화면 스레드에 넘겨요.

모듈 사이의 의존 관계

상자를 누르면 그 모듈이 부르는 것(파랑)과 부르는 곳(분홍)이 강조돼요. 점선은 함수 안에서 필요할 때만 불러오는 늦은 import예요(시작을 가볍게 하려는 선택).

import 그래프모듈을 눌러 보세요
의존의 방향 규칙 아래 층은 위 층을 몰라요. flow.py·routine.py·pet.py 는 화면 라이브러리를 전혀 불러오지 않아서 가짜 시계·가짜 입력으로 바로 시험할 수 있어요. cat.py 한 곳에서만 모든 부품을 조립해요.
