시각 판단 규칙 — 직접 해 보기

Scheduler.due_slot 은 "오늘 이미 지난 시각 중 가장 최근 것이 아직 안 돌았으면 그것"을 돌려줘요. 아래에서 시각·마지막 실행·최대 지연을 바꿔 보세요.

CHECK_EVERY = 20.0                       # 초
def due_slot(self, name, now):
    sch = settings.data["schedules"].get(name, {})
    if not sch.get("enabled"): return None
    last = settings.data["last_run"].get(name, "")
    best = None
    for t in sorted(x for x in sch.get("times", []) if valid_time(x)):
        slot = "%s %s" % (now.date().isoformat(), t)                  # "2026-10-16 09:00"
        if slot <= now.strftime("%Y-%m-%d %H:%M"): best = slot        # 오늘 지난 칸 중 가장 최근
    max_age = sch.get("max_age_min")
    if best and max_age:                                              # 매시 알림: 오래 지난 칸은 따라잡지 않는다
        if (now - strptime(best)).total_seconds() / 60 > max_age: return None
    return best if best and best > last else None                     # 문자열 비교로 충분 (같은 형식)

def tick(self, mono_now, now=None):
    if mono_now < self._next: return
    self._next = mono_now + CHECK_EVERY
    if self.quiet and self.quiet(): return                            # 잠자는 시간: 깬 뒤 가장 최근 하나만 따라잡는다
    for name in self.jobs:
        if name in self._running: continue
        slot = self.due_slot(name, now or datetime.now())
        if slot:
            settings.data["last_run"][name] = slot; settings.save()  # 실행 '전에' 적는다: 실패해도 같은 시각에 되풀이하지 않는다
            self.run(name)

놓친 알림 따라잡기

컴퓨터가 꺼져 있었으면 켜진 뒤 첫 점검(최대 20초)에서 그날 놓친 것 중 가장 최근 하나만 해요(여러 개를 쏟아내지 않음). 매시 알림은 max_age_min=180 안의 것만(가져오는 내용이 "지금" 기준이라 괜찮음).

같은 시각 두 번 금지

last_run[이름] 에 마지막으로 처리한 칸 문자열을 저장해요. 이 값은 실행 전에 적어서 실패해도 되풀이하지 않고, 결과는 재시도 규칙이 맡아요.

설정을 저장해도 안 울리게

mark_past_done(): 설정을 저장할 때 켜짐/시각이 바뀐 알림만 오늘 이미 지난 칸을 "한 것"으로 표시해요(저장하자마자 울리지 않게). 바뀌지 않은 알림은 그대로 둬서, 자리를 비운 사이 놓친 알림이 설정만 열었다 닫았다고 사라지지 않아요.

멈춘 동안 붙잡기

자리 비움·전체 화면 중에도 알림 일은 제 시각에 시작해요. 결과는 held 목록에 쌓아 두었다가(최대 12건, 매시 알림은 일정은 최근 것·메일은 합쳐서 6건) 돌아오면 1.5초 뒤 보여 줘요. '지금 시험'으로 한 것은 바로.

일시적 오류는 조용히 재시도

인터넷이 아직 안 붙은 켠 직후·절전 복귀 직후를 위해, retry=True 오류는 60초 → 180초 → 600초 뒤에 다시(오류 풍선은 마지막까지 실패했을 때만). 직접 시험한 것은 재시도 없이 바로 결과 표시.

잠자는 시간

scheduler.quiet = routine.is_night. 밤에는 정해 둔 알림 작업을 시작하지 않고, 깬 뒤 첫 점검에서 따라잡아요.

# 보조 프로세스 쪽
def main():
    try:
        req = json.loads(sys.stdin.read())
        out = {"ok": True, "result": HANDLERS[req["kind"]](req)}
    except Exception as e:
        known = e.__class__.__name__ in ("CalendarError", "GeminiError", "MailError", "VTError")
        out = {"ok": False, "error": str(e) if known else "작업을 못 했다냥 (%s)" % e.__class__.__name__,
               "retry": bool(getattr(e, "retry", False))}
    sys.stdout.write(json.dumps(out))      # ensure_ascii=True(기본): 한글도 \uXXXX → 순수 ASCII, cp949/UTF-8 문제 없음
    return 0

# 본체 쪽
def call(kind, **params):
    p = subprocess.run(_command(), input=json.dumps(dict(params, kind=kind)), capture_output=True, text=True,
                       encoding="utf-8", timeout=TIMEOUTS.get(kind, 45.0), creationflags=0x08000000)
    # TimeoutExpired → NetError("서버가 대답이 없다냥 (시간 초과)", retry=True)
    data = json.loads(p.stdout)            # 깨지면 NetError("네트워크 작업이 이상하게 끝났다냥")
    if not data.get("ok"): raise NetError(data.get("error"), bool(data.get("retry")))
    return data["result"]
