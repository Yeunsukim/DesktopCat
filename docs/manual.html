UserManual

바탕화면 고양이를 설치하고, 놀고, 알림을 받고, 안전하게 쓰는 방법을 처음부터 차근차근 적었어요.
그림과 움직이는 연습장으로 직접 해 보면서 읽어 보세요.

설치 5분 관리자 권한 필요 없음 알림 4가지 경비 4가지 쥐

어떤 프로그램인가요

윈도우 바탕화면 위에서 돌아다니고, 졸고, 밥 달라고 조르는 고양이예요. 귀엽기만 한 것이 아니라, 정해 둔 시각이 되면 일정·소식·새 메일을 풍선으로 알려 주고, 뒤에서 수상한 행동을 지켜보는 비서 겸 경비원이에요.

놀기

살아 있는 고양이

혼자 걷고, 창 위로 뛰어오르고, 하품하고, 잠자요. 쓰다듬고 집어 올리고 던질 수도 있어요. 털색은 여섯 가지.

런처

반원 앱 런처

고양이를 누르면 머리 위에 반원이 열려요. 캘린더·Gmail·구글·유튜브와 내가 등록한 프로그램을 바로 열어요.

알림

정해 둔 시각의 알림

오늘 일정, 오늘의 소식(날씨·뉴스·시세), 어제 한 일 요약, 매시 정각의 일정과 새 메일.

생활

하루 리듬

22시~7시에는 구석에서 자고, 밥 시간(아침·점심·저녁)에는 밥 달라고 조르고, 일하다 쉬라고 놀아 달라고 해요.

경비

경비 고양이

랜섬웨어, 새 자동 시작·수상한 프로그램, 카메라·마이크를 쓰는 낯선 프로그램, 내려받은 파일을 지켜보고 알려요.

안심

죽지 않게 지켜봐요

고양이가 멈추면 작은 지킴이가 몇 초 안에 다시 살려요. 설치도 삭제도 관리자 권한이 필요 없어요.

꼭 알아 두세요 경비 고양이는 백신을 대신하지 않아요. 파일을 지우거나 프로그램을 끄거나 막지 않고, "수상하다"고 알려 주기만 해요. 조치는 경보 창의 버튼을 직접 눌렀을 때만 해요.

내 컴퓨터에서 되나요?

항목필요한 것
윈도우Windows 10 / 11 (64비트). 맥·리눅스는 안 돼요.
권한일반 사용자 계정이면 돼요 (관리자 권한 필요 없음).
자원평소 CPU 코어 1개의 약 1%, 메모리 약 110MB 정도로 가볍게 설계했어요.
인터넷알림 기능(일정·소식·메일)에만 필요해요. 고양이와 노는 것, 경비의 대부분은 인터넷 없이 돼요.
모니터여러 개여도 돼요. 고양이가 걸어서 건너가요. (배율이 서로 다르면 보조 모니터에서 위치가 살짝 어긋날 수 있어요.)

설치하기

나눠 받은 DesktopCat_Setup.exe 파일 하나면 돼요. 아래 순서를 눌러 보세요.

DesktopCat_Setup.exe 를 더블클릭하세요. 윈도우가 "알 수 없는 게시자" 같은 경고를 보여 주면, 믿을 수 있는 곳에서 받은 파일인지 확인한 뒤 추가 정보 → 실행 을 눌러요.

기본 위치는 내 계정 폴더라서 그대로 두면 돼요. 아래 네 가지 중 고르세요.

설치닫기

진행 막대가 차오르고 "실행 중인 고양이를 끄는 중 → 파일을 설치하는 중 → 바로가기와 설정을 만드는 중" 순서로 알려 줘요. 이미 설치되어 있으면 새 버전으로 바꿔치기하고, 도중에 실패해도 이전 설치가 남아요. 보통 몇 초~1분이면 끝나요.

끝나면 "설치가 끝났냐옹~" 이라고 나와요. 바탕화면에 고양이가 나타나고, 작업 표시줄 오른쪽 아래(트레이)에 분홍 동그라미 속 고양이 아이콘이 생겨요. 안 보이면 위쪽 화살표(^)를 눌러 숨은 아이콘을 확인하세요.

고양이가 "냐옹~" 하고 말풍선을 띄워요. 이제 놀 준비 끝! 다음 장 "고양이와 놀기" 로 가세요.

설치 옵션 설명

옵션하는 일나중에 바꾸려면
윈도우를 켤 때 자동 실행컴퓨터를 켜면 고양이도 같이 나와요. 꺼지면 스스로 다시 켜져요.다시 설치할 때 끄거나, 윈도우 설정 → 앱 → 시작 프로그램
시작 메뉴 바로가기시작 메뉴에서 "데스크탑 고양이"로 켤 수 있어요.시작 메뉴에서 바로가기를 지워요
바탕화면 바로가기바탕화면에 아이콘을 하나 더 만들어요.아이콘을 지워요
설치 후 바로 실행설치가 끝나면 바로 고양이를 불러와요.—
고급: 창 없이 설치하기 (명령줄) 
DesktopCat_Setup.exe --silent                       # 기본 위치, 시작 메뉴 바로가기 + 자동 실행 포함
DesktopCat_Setup.exe --silent --dir D:\Cat          # 설치 위치 지정
DesktopCat_Setup.exe --silent --no-startup --desktop --no-run

실패하면 %TEMP%\DesktopCat_setup_error.log 에 이유가 적혀요.

설치가 안 될 때 "실행 중인 고양이를 끌 수 없습니다" 라고 나오면 트레이의 고양이 아이콘을 우클릭 → 종료 한 뒤 다시 설치하세요.

처음 켜면 이런 일이 있어요

바로 고양이가 화면 아래(작업 표시줄 위)에 나타나 "냐옹~" 하고 인사해요. 크기는 평소 실제 고양이의 80% 정도예요.
8초 뒤 웹 주소로 등록한 앱이 있으면 그 사이트의 아이콘을 인터넷에서 조용히 받아 와요.
1~2분 뒤 경비 고양이가 첫 점검을 해요. 지금 컴퓨터에 있는 자동 시작 항목을 "평소 것"으로 기억만 하고 알리지 않아요. 그 뒤 새로 생긴 것만 알려요.
처음 24시간 카메라·마이크를 쓰는 프로그램은 알림 없이 "평소 쓰던 프로그램"으로 기억만 해요(배우는 기간).
다음 정각부터 매시 정각 알림이 켜져 있어요(캘린더가 연결되어 있을 때). 그 밖의 알림은 아직 꺼져 있어서 설정에서 켜야 와요.
바탕화면 아이콘을 발로 차요? 처음에는 꺼져 있어요. 우클릭 메뉴의 "아이콘 차기"를 켜야 해요. 켜도 종료하거나 "아이콘 원래대로"를 누르면 아이콘이 모두 제자리로 돌아와요.

고양이와 놀기

고양이는 혼자서도 잘 놀아요. 하지만 여러분이 해 줄 수 있는 일도 많아요. 아래 연습장에서 먼저 눌러 보고 끌어 보세요 — 실제 고양이와 같은 방식이에요.

조작 연습장
내 작업 창 (고양이가 올라설 수 있어요)
고양이를 클릭하면 앱 런처가 열려요. 끌어서 놓으면 떨어지고, 몸 위에서 쓱쓱 문지르면 좋아해요.

조작 한눈에 보기

이렇게 하면이런 일이 일어나요
클릭고양이가 앉아서 고개를 갸웃(생각하는 척)하고, 머리 위에 반원 앱 런처가 열려요. 다시 클릭하면 닫혀요.
몸 위에서 쓱쓱 문지르기 (클릭 아님)쓰다듬기예요. 눈을 감고 골골골 하며 기분이 좋아져요. 자고 있을 땐 "…깼냐옹…" 하고 투덜대요.
끌어서 놓기고양이가 대롱대롱 매달리고("냥?! 뭐냐옹?!"), 놓으면 떨어져요. 끌면서 놓으면 던져져요. 창 윗변·작업 표시줄 위에 내려앉아요.
우클릭메뉴가 열려요 (아래 설명). 트레이 아이콘을 우클릭해도 같은 메뉴예요.
가만히 두기고양이가 알아서 걷고, 앉고, 그루밍하고, 하품·기지개, 낮잠을 자요. 해 뜰 때와 질 때는 활발하고 한낮엔 낮잠을 많이 자요.

배고픔과 기분

고양이는 배고픔과 기분이 있어요(메뉴 맨 위에 퍼센트로 보여요). 시간이 지나면 배고파지고, 배가 고프면 기분이 나빠지고 걸음이 느려져요. 밥을 주면 좋아지고, 놀아 주면 기분이 크게 올라요.

밥 주기

간식은 배고픔이 10% 아래(배부름)면 거절해요("배부르당..옹~"). 밥 시간에 조를 때는 배불러도 먹어요(정식 식사는 더 많이 먹어요).

놀아주기 (털실공)

엉덩이를 씰룩하다 털실공을 덮치고, 툭 치고, 쫓아가고, 세 번 놀면 끌어안고 뒷발킥! 끝나면 기분이 크게 올라요.

꺼 둔 동안

컴퓨터를 꺼 둔 동안에도 시간이 흘러요. 단 굶어 죽지는 않아요(배고픔 최대 85%).

고양이가 가끔 말을 걸어요 40~90초 간격으로 기분에 맞는 혼잣말을 해요. 배고프면 "밥 줘랑..옹~", 기분이 좋으면 "♪ 랄라냐옹~", 우울하면 "… 냐앙…".

우클릭 메뉴와 트레이

고양이를 우클릭하거나 작업 표시줄 오른쪽 아래의 고양이 아이콘을 우클릭하면 메뉴가 열려요. 항목에 마우스를 올려 보세요.

오늘도 반갑다냥~
배고픔 48% · 기분 62%

메뉴 맨 위

고양이 얼굴, 한마디, 지금 배고픔·기분이 나와요. 아래 항목에 마우스를 올려 보세요.

트레이 아이콘이 안 보여요

작업 표시줄 오른쪽 아래에서 위쪽 화살표(^) 를 눌러 숨겨진 아이콘을 보세요. 아이콘을 작업 표시줄로 끌어다 놓으면 항상 보여요. 탐색기가 다시 시작되어 아이콘이 사라져도 고양이가 1분 안에 다시 만들어요.

앱 런처와 앱 등록

고양이를 클릭하면 머리 위에 반원 모양으로 아이콘이 펼쳐져요. 기본으로 구글 캘린더 · Gmail · 구글 · 유튜브가 있고, 내가 쓰는 프로그램·웹·명령·윈도우 도구를 더할 수 있어요.

런처 쓰는 법

  • 아이콘에 마우스를 올리면 이름이 아치 위에 나와요.
  • 아이콘을 누르면 열리고 런처가 닫혀요.
  • 한 쪽에 5개. 더 있으면 양 끝 ‹ › 화살표로 쪽을 넘겨요(아이콘이 굴러가요).
  • 닫기: 고양이를 다시 클릭 · 바깥 클릭 · Esc · 8초 동안 마우스가 아치 위에 없을 때.

이럴 땐 안 열려요

고양이가 점프·낙하·집어 올려지는 중일 때는 열리지 않아요. 잠깐 뒤 다시 눌러 보세요. 잠자는 시간에는 구석에서 자고 있어서 눌러도 일어나기만 해요.

앱 등록하기 (우클릭 → "앱 등록…")

고양이를 우클릭 → 앱 등록… 을 누르면 분홍색 등록 창이 열려요. 고양이 창 위에 떠서 다른 창 뒤에 숨지 않아요.

등록한 앱 지우기

고양이를 우클릭 → 등록한 앱 지우기 → 지울 앱 이름을 고르면 바로 지워져요(되돌릴 수 없어요). 기본 아이콘 4개는 지울 수 없어요.

고양이를 우클릭 → 설정… 으로 열어요. 위쪽에 탭이 여섯 개 있어요: 캘린더 · 소식 · 메일 · 어제 한 일 · 생활 · 경비. 알림 기능은 연결(키·주소 넣기) → 시각 정하기 → 지금 시험 → 저장 순서로 설정해요.

저장 버튼

저장해도 창은 닫히지 않아요 (다른 탭을 계속 볼 수 있게). 다 했으면 닫기. 저장하지 않고 닫으면 입력한 것이 사라져요. 단, 지금 시험은 누르는 순간 현재 입력값을 먼저 저장해요.

비밀 칸 (주소·키·비밀번호)

입력한 것은 점(●)으로 가려져요. 보이기 체크로 확인할 수 있어요. 저장하면 윈도우 계정으로 암호화되어 저장돼요. 저장된 뒤에는 화면에 다시 보여 주지 않고 "저장된 … 있다냥"만 알려 줘요. 바꾸려면 새로 넣고, 지우려면 저장된 … 지우기.

안내 카드

"연결 방법" 카드는 번호 순서와 바로가기 링크가 있어요. 이미 연결했으면 접혀 있고, 아직이면 펼쳐져 있어요. 링크(파란 밑줄)를 누르면 브라우저가 열려요.

시각 목록 알림 시각은 "HH:MM"(24시간)으로 하루에 여러 번 넣을 수 있어요. 시각을 바꿔서 저장하면 이미 지난 시각의 알림은 한 것으로 쳐서 저장하자마자 울리지 않아요.

캘린더 연결하기

구글 캘린더의 비공개 주소(iCal)를 넣으면 고양이가 오늘 일정과 앞으로 몇 시간의 일정을 읽어 알려 줘요. 읽기만 하고 일정을 바꾸거나 지우지 않아요.

설정 창의 안내 카드에서 calendar.google.com 설정 열기 ↗ 를 눌러요. 구글 계정으로 로그인되어 있어야 해요.

왼쪽 목록에서 "내 캘린더의 설정" 아래의 일정을 읽고 싶은 캘린더(보통 내 이름)를 눌러요.

아래로 내려가 "캘린더 통합" 칸에서 "iCal 형식의 비공개 주소" 를 찾아 복사해요. (https://calendar.google.com/calendar/ical/…/basic.ics 로 끝나요.) "공개 주소"가 아니라 "비공개 주소"예요.

설정의 캘린더 탭 칸에 붙여 넣고 지금 시험해 보기 를 눌러요. 오늘 일정이 풍선으로 나오면 성공! 상태 줄이 "저장된 주소가 있다냥" 으로 바뀌어요.

정해 둔 시각에 오늘 일정을 알려 주기 를 체크하고 시각을 넣어요. 기본은 09:00. 저장!

이 주소는 비밀이에요. 이 주소를 아는 사람은 내 캘린더를 읽을 수 있어요. 남에게 알리지 마세요. 고양이는 이 주소를 윈도우 계정 암호화로 저장하고, 오류 메시지·로그에도 넣지 않아요.

말투 고양이의 혼잣말은 "~냥/~옹"이지만, 소식 내용은 또렷한 존댓말로 나와요. 정보가 말투에 묻히지 않게요.
내보내는 정보 소식을 만들 때 날씨·뉴스·시세 자료와 프롬프트가 구글 Gemini로 전송돼요. 무료 한도가 있어요(넘으면 "오늘 사용량을 다 썼다냥").

매시 정각에 새 메일이 왔는지 확인해 누구에게서 왔는지만 알려 줘요. 제목·본문은 가져오지 않고, 메일을 읽음으로 바꾸거나 지우거나 보내지도 않아요(읽기 전용). 구글 계정의 앱 비밀번호를 써요.

myaccount.google.com 앱 비밀번호 ↗ 에서 이름을 아무거나(예: 고양이) 입력해 만들면 16자리가 나와요. 복사해 두세요. (공백이 섞여 보여도 괜찮아요.)

설정의 메일 탭에 Gmail 주소(예: name@gmail.com)와 앱 비밀번호를 넣고 지금 새 메일 확인해 보기 를 눌러요.

처음 확인할 때는 지금 있는 메일을 기준점으로만 삼고 "안 읽은 메일이 N통 있다옹" 이라고만 알려요(쌓인 메일을 한꺼번에 알리지 않게). 그 뒤 새로 온 메일만 알려요.

어제 한 일 요약

내가 컴퓨터에서 어떤 프로그램을 얼마나 썼는지 기록해 두었다가, 다음 날 아침 AI가 요약해서 보여 주는 기능이에요. 기본은 꺼져 있어요. 켜기 전에 무엇이 저장되는지 꼭 확인하세요.

저장하는 것저장하지 않는 것

AI 요약을 만들 때 그날의 기록(프로그램·창 제목)이 구글 Gemini로 전송돼요. 무료 등급에서는 구글이 서비스 개선에 쓸 수 있다고 안내돼 있어요. 민감한 제목이 걱정되면 제외 단어를 넣거나 "기록 그대로 보기"만 쓰세요(AI에 보내지 않아요).

설정의 어제 한 일 탭 맨 위 체크 "컴퓨터에서 쓴 프로그램과 창 제목을 기록하기" 를 체크하면 확인 창이 나와요. 내용을 읽고 예를 누르면 켜져요. 바로 적용돼요(저장 버튼 필요 없음). 상태 줄에 "기록 중이다냥 · 오늘 12분" 처럼 나와요.

"제외할 단어"에 한 줄에 하나씩 넣어요. 이 단어가 창 제목이나 프로그램 이름에 들어 있으면 내용 없이 (제외됨) 으로만 기록돼요.

하루가 지나면 날짜 목록이 생겨요(최근 30일). 날짜를 고르고 AI 요약 보기(Gemini 키 필요) 또는 기록 그대로 보기를 눌러요. 그대로 보기는 프로그램별 시간과 창 제목 목록이에요.

매일 정해 둔 시각에 어제 한 일을 요약해서 알려 주기 를 체크하고 시각(기본 09:30)을 넣으면, 그 시각에 "어제 한일이다~ 냐옹~" 풍선과 함께 요약 창이 떠요. 어제 기록이 없거나 너무 적으면(2분 미만) 아무것도 안 보여 줘요.

경보 창 읽는 법 — 눌러 보세요

경보 창 예시 (시험 경보)
중요한 약속 고양이는 절대 혼자 파일을 지우거나 프로그램을 끄지 않아요. "종료…" 버튼은 내가 누르고 확인 창에서 한 번 더 예를 눌렀을 때만 작동하고, 윈도우 핵심 프로그램에는 아예 버튼이 안 보여요.

랜섬웨어가 의심될 때 (위험 경보)

  1. 인터넷을 바로 끊어요. 와이파이를 끄거나 랜선을 뽑아요.
  2. 의심 프로그램을 끝내거나, 안 되면 컴퓨터를 종료하세요. 켜 둘수록 더 많은 파일이 암호화돼요.
  3. 몸값은 내지 마세요. 내도 복구가 안 될 수 있어요. 백신(알약 등)과 전문가에게 알리세요.
  4. 백업 장치(외장 디스크·클라우드)를 연결하지 마세요. 그쪽도 암호화될 수 있어요.
"쥐 발견!"인데 나는 아무것도 안 했어요 ① 설정에서 "시험 경보"를 누르지 않았나요? (제목에 "시험 경보"가 있으면 시험이에요) ② 내가 폴더에 있는 숨김 문서(!_고양이미끼_회의록.docx 등)를 열거나 지우지 않았나요? 그 파일은 고양이가 둔 가짜 문서예요. 건드렸다면 경보가 맞아요. ③ 대량 압축 풀기·복사는 경보가 안 울리도록 설계했지만, 이상하면 알려 주세요.

알림은 언제 오나요?

"9시에 알림을 맞췄는데 컴퓨터를 9시 30분에 켰어요. 알림이 올까요?" — 이런 궁금증을 풀어 주는 시뮬레이터예요. 고양이가 쓰는 실제 규칙과 같아요. 시각과 컴퓨터 켜진 시간을 바꿔 보세요.

규칙 정리

정해진 시각이 되면

컴퓨터가 켜져 있으면 20초 안에 알림 작업이 시작돼요. 인터넷에서 가져오는 데 몇 초~몇십 초 걸려요.

컴퓨터가 꺼져 있었다면

켜진 뒤 첫 점검에서 오늘 놓친 알림 중 가장 최근 것 하나만 따라잡아요. (여러 개가 한꺼번에 쏟아지지 않아요.) 매시 알림은 3시간 안에 놓친 것만 따라잡아요.

잠자는 시간이면

알림 작업을 시작하지 않아요. 깬 뒤(07:00) 첫 점검에서 가장 최근 놓친 것을 따라잡아요.

자리를 비웠거나 게임 중이면

알림 작업은 제 시각에 해요. 하지만 풍선은 돌아왔을 때 보여 줘요(고양이가 멈춰 있어서 아무도 못 보고 사라지는 걸 막으려고요). 입력이 10분 넘게 없으면 자리 비움, 전체 화면 앱이 덮으면 숨어요.

인터넷이 안 될 때

켠 직후·절전 복귀 직후에는 인터넷이 아직 안 붙었을 수 있어서, 1분 → 3분 → 10분 뒤에 조용히 다시 시도해요. 끝내 안 되면 "…못 가져왔다냥" 풍선이 나와요.

설정을 바꿔 저장하면

시각이나 켜짐을 바꾼 알림은 이미 지난 시각을 한 것으로 쳐요. 그래서 저장하자마자 울리지 않아요. 바꾸지 않은 알림은 그대로예요.

같은 시각에 두 번 안 와요 알림은 시각 칸마다 한 번만 실행하고 기록해요. 매시 정각에 "오늘 일정"도 같은 시각이라면 겹치지 않게 매시 알림의 일정 부분은 건너뛰어요.

알림이 안 올 때 점검표

  1. 설정에서 그 알림이 켜져 있고 저장했나요? (알림마다 켜기 체크가 있어요)
  2. 주소·키·비밀번호가 연결되어 있나요? 상태 줄이 "저장된 … 있다냥" 인지 보세요.
  3. 지금 시험해 보기가 되나요? 시험이 안 되면 연결 문제예요(메시지를 읽어 보세요).
  4. 잠자는 시간이거나 컴퓨터가 꺼져 있진 않았나요? (위 시뮬레이터)
  5. 고양이가 실행 중인가요? 트레이에 아이콘이 있어야 해요.
  6. 그래도 안 되면 %LOCALAPPDATA%\DesktopCat\cat_error.log 를 열어 마지막 줄을 보세요(원인이 적혀 있어요).

문제 해결 FAQ

고양이가 안 보여요
  • 트레이(작업 표시줄 오른쪽 아래, ^ 안쪽)에 고양이 아이콘이 있는지 보세요. 없으면 시작 메뉴에서 "데스크탑 고양이"를 켜세요.
  • 전체 화면 앱(게임·동영상)이 떠 있으면 숨어요. 앱을 닫거나 창 모드로 바꾸면 돌아와요.
  • 10분 넘게 컴퓨터를 안 만지면 멈춰 있어요(자리 비움). 마우스를 움직이면 이어서 놀아요.
  • 모니터를 뺐다 꽂은 뒤엔 가장 가까운 모니터 바닥으로 데려와요.
고양이가 멈추거나 사라졌다가 다시 나타났어요

정상이에요! 고양이가 응답이 없으면(90초) 지킴이가 강제로 껐다가 몇 초 뒤 다시 켜요. 메모리나 시스템 자원이 샐 때도 스스로 껐다 켜요. 사용자가 종료를 눌렀을 때만 완전히 꺼져요. 자세한 기록은 cat_guard.log 에 있어요.

작업 관리자에서 끝냈는데 되살아나요

지킴이가 되살리는 거예요. 완전히 끄려면 트레이 아이콘 우클릭 → 종료. 명령줄에서는 DesktopCat.exe --quit.

바탕화면 아이콘이 이상한 곳에 있어요 / 아이콘을 차지 않아요
  • 아이콘 차기는 처음엔 꺼져 있어요. 우클릭 → "아이콘 차기"를 체크하세요.
  • 바탕화면 자동 정렬이 켜져 있으면 못 차요. 바탕화면 우클릭 → 보기 → "자동 정렬" 해제(시작할 때 안내가 나와요).
  • 아이콘이 제자리에 없으면 우클릭 → 아이콘 원래대로. 고양이를 정상 종료해도 모두 돌아와요. 갑자기 꺼졌다면 다음 시작 때 먼저 제자리로 돌려놓아요. 내가 직접 옮긴 아이콘은 건드리지 않아요.
보조 모니터에서 고양이 위치가 어긋나요

모니터마다 화면 배율이 다르면 생길 수 있어요(시작할 때 안내가 나와요). 윈도우 설정 → 디스플레이에서 배율을 같게 맞추세요.

일정 알림이 안 와요 / "일정을 못 가져왔다냥"
  • "캘린더 주소가 틀렸거나 바뀌었다냥" → 비공개 주소를 다시 복사하세요(공개 주소는 안 돼요).
  • "연결을 못 했다냥 / 시간 초과" → 인터넷 문제예요. 고양이가 1·3·10분 뒤 조용히 다시 해 봐요.
  • 그 밖에는 앞의 "알림이 안 올 때 점검표"를 보세요.
Gemini 오류가 나요 ("키가 틀렸다", "사용량을 다 썼다")
  • "키가 틀렸거나 만료" → 키를 다시 복사해 넣으세요(공백·한글 없이).
  • "사용량을 다 썼다 / 한도에 걸렸다" → 무료 한도예요. 내일 다시 하거나, "구글 검색 사용" 체크가 켜져 있다면 끄세요(무료 키는 검색 도구가 막혀 있어요).
  • "모델 이름을 못 찾겠다" → 설정의 모델 칸을 비우세요(기본 모델 사용).
메일 로그인이 안 돼요

일반 구글 비밀번호가 아니라 앱 비밀번호 16자리를 넣어야 해요. 2단계 인증이 켜져 있어야 만들 수 있고, 회사/학교 계정이거나 패스키만 쓰면 안 될 수 있어요. 구글이 "보안 확인"을 요구한다면 브라우저에서 그 계정으로 Gmail에 한 번 로그인해 확인한 뒤 다시 해 보세요.

"쥐 발견!" 경보가 떴어요. 진짜인가요?

제목에 (시험 경보)가 있으면 시험이에요. 아니라면 경보 창의 설명을 읽어 보세요. 미끼 파일이 건드려졌다는 내용이면 내가 그 숨김 문서를 열거나 지우지 않았는지 떠올려 보세요. 확실하지 않으면 랜섬웨어 4단계 카드를 따라 하세요(인터넷 끊기 → 의심 프로그램 끝내기 → 몸값 내지 않기 → 백업 장치 연결하지 않기).

자꾸 같은 프로그램을 의심해요

내가 아는 프로그램이면 경보 창에서 허용 목록에 추가를 누르세요. 그 프로그램은 다시 알리지 않아요. 잘못 허용했다면 설정 → 경비 → 허용 목록 지우기.

카메라·마이크 알림이 갑자기 와요

처음 24시간은 알림 없이 기억만 하고, 그 뒤 처음 보는 프로그램이 쓸 때만 알려요. 내가 쓰던 앱이면 허용 목록에 추가하세요. 모르는 앱이면 스파이웨어일 수 있으니 의심하고 백신으로 검사하세요.

컴퓨터가 느려졌어요

평소 CPU 코어 1개의 약 1%, 메모리 약 110MB예요. 경비를 켜도 거의 늘지 않아요. 파일을 수만 개 한꺼번에 복사·압축 해제하는 동안에는 폴더 감시가 잠깐 바빠질 수 있어요. 그래도 부담되면 설정 → 경비의 민감도를 "느슨"으로 하거나 폴더 감시를 끄세요. 실행 옵션으로 --low-priority(우선순위를 낮춤)도 있어요.

글자가 깨져 보여요 / 이모티콘이 안 보여요

풍선에는 이모티콘을 쓰지 않아요. 설정 창의 버튼·제목에도 없어요. 고양이가 직접 하는 말풍선에만 이모티콘이 들어 있어요. 글꼴은 맑은 고딕을 써요.

업데이트와 삭제

새 버전으로 바꾸기

새 DesktopCat_Setup.exe 를 그냥 한 번 더 실행하세요. 실행 중인 고양이를 알아서 끄고, 이전 설치를 안전하게 바꿔치기해요. 설정·기록은 그대로 남아요(데이터 폴더는 따로 있어요).

삭제하기

윈도우 설정 → 앱 → 설치된 앱에서 "데스크탑 고양이" → 제거, 또는 설치 폴더의 uninstall.exe. 묻는 순서: ① "삭제할까요?" ② "고양이의 기록도 함께 지울까요?"

"기록도 지울까요?"지워지는 것남는 것
예배고픔·기분, 설정(앱·알림 시각), 암호화해 저장한 키·주소, 활동 기록, 경비 기록·VirusTotal 키 — 모두없음
아니요프로그램 파일, 바로가기, 자동 실행 등록기록·설정 (다시 설치하면 이어서 써요)
숨김 미끼 파일은 "기록은 남기고 삭제"를 골라도 항상 같이 지워져요(고양이가 만든 것만). 문서 폴더에 이상한 숨김 파일이 남을 걱정은 안 해도 돼요. 삭제 프로그램은 자동 실행 해제와 바탕화면 아이콘 원위치도 해 줘요.

명령줄 삭제: uninstall.exe --silent (기록 남김) · uninstall.exe --silent --purge (기록까지 삭제).
