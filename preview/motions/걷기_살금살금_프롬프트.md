# 걷기 · 살금살금 · 종종걸음 다시 받기 (나노 바나나 문장)

## 왜 다시 받나
이전 그림은 (1) 뒷다리 하나가 거의 안 움직이거나 앞 3컷에서 똑같았고, (2) 꼬리가 앞 3컷은 내려가고 뒤 3컷은 올라갔고, (3) 6번째 컷에서 1번째 컷으로 이어지지 않았습니다.
그래서 이번에는 **네 발이 컷마다 정확히 어디에 있는지**를 정해서 요청합니다 (걷기 한 바퀴를 6등분한 위치를 계산한 값입니다).

## 사용 방법
1. 기준 사진(`assets/cat_lying.png`)을 첨부하고 아래 "공통 앞부분"을 붙여 넣은 뒤 걷기 또는 살금살금 문장을 이어 붙입니다.
2. 결과가 마음에 안 들면, 6컷을 한 번에 받지 말고 **컷 번호 하나씩** 받는 방법도 있습니다 (마지막 칸 참고).
3. 받은 그림을 `preview/ai_motions`에 **같은 이름으로 덮어쓰면** 됩니다 (`1-이동-걷기.png`, `1-이동-살금살금.png`, `1-이동-종종걸음.png`).

컷4: 가까운 뒷발=몸 뒤쪽에 딛고 있음 / 가까운 앞발=몸 바로 아래 약간 앞에 딛고 있음 / 먼 뒷발=몸보다 가장 앞에서 막 땅에 닿음 / 먼 앞발=땅에서 막 떨어져 앞으로 나가는 중(들림)
컷5: 가까운 뒷발=땅에서 떨어져 뒤에서 앞으로 나가는 중(들림) / 가까운 앞발=몸 뒤쪽에 딛고 있음 / 먼 뒷발=몸 앞쪽에 딛고 있음 / 먼 앞발=앞으로 뻗으며 공중에 들려 있음
컷6: 가까운 뒷발=공중에 들려 몸 아래 앞쪽으로 나가는 중 / 가까운 앞발=가장 뒤에서 딛고 있다가 막 떨어지려 함 / 먼 뒷발=몸 바로 아래에 딛고 있음 / 먼 앞발=가장 앞에서 막 땅에 닿음

몸과 꼬리: 몸통 높이는 거의 일정하고 걸음에 맞춰 아주 살짝만 출렁입니다. 머리는 앞을 보고 목은 자연스럽게 앞으로 뻗습니다.
꼬리는 6컷 모두 같은 모양과 같은 높이입니다: 엉덩이에서 뒤쪽으로 낮게 늘어졌다가 끝만 위로 살짝 휘어 올라가는 모양. 꼬리가 컷마다 위로 솟거나 내려가면 안 됩니다.
한 컷 안에서 발이 땅에 닿는 곳(발바닥)은 모두 같은 바닥선 위에 있습니다.

컷3: 가까운 뒷발=몸 바로 아래에 딛고 있음 / 가까운 앞발=앞에서 막 닿음 / 먼 뒷발=접힌 채 몸 아래 앞쪽으로 나가는 중(들림) / 먼 앞발=가장 뒤에서 막 떨어지려 함
컷4: 가까운 뒷발=뒤쪽에 딛고 있음 / 가까운 앞발=몸 바로 아래 약간 앞에 딛고 있음 / 먼 뒷발=몸 앞쪽에서 막 닿음 / 먼 앞발=막 떨어져 낮게 앞으로 나가는 중(들림)
컷5: 가까운 뒷발=접힌 채 뒤에서 앞으로 나가는 중(들림) / 가까운 앞발=뒤쪽에 딛고 있음 / 먼 뒷발=앞쪽에 딛고 있음 / 먼 앞발=낮게 앞으로 뻗으며 들려 있음
컷6: 가까운 뒷발=접힌 채 몸 아래 앞쪽으로 나가는 중(들림) / 가까운 앞발=가장 뒤에서 막 떨어지려 함 / 먼 뒷발=몸 바로 아래에 딛고 있음 / 먼 앞발=앞에서 막 닿음

## 3. 종종걸음

```
동작: 기분 좋은 고양이가 경쾌하게 종종걸음(트롯)으로 걷습니다. 평소 걷기보다 빠르고 보폭이 크며, 대각선에 있는 두 발이 항상 함께 움직입니다.
용어: "가까운 쪽"은 카메라에 가까운 다리, "먼 쪽"은 카메라에서 먼 다리입니다. 앞=화면 오른쪽, 뒤=화면 왼쪽입니다.
발 두 쌍: A쌍 = 가까운 앞발 + 먼 뒷발 (둘이 같은 순간에 같은 동작) / B쌍 = 먼 앞발 + 가까운 뒷발 (둘이 같은 순간에 같은 동작). A쌍이 땅을 딛을 때 B쌍은 공중에 있고, 반대도 마찬가지입니다.
네 발이 컷마다 아래 위치에 있어야 합니다. 이 표를 정확히 지켜 주세요. 특히 뒷다리 두 개도 앞발처럼 크게 앞뒤로 움직여야 합니다.

컷1: A쌍=몸보다 가장 앞에서 막 땅에 닿음 / B쌍=가장 뒤에서 막 땅을 떼려 함
컷2: A쌍=몸 앞쪽에 딛고 있음 / B쌍=공중에 들려 몸 약간 뒤쪽에서 앞으로 나가는 중
컷3: A쌍=몸 약간 뒤쪽에 딛고 있음 / B쌍=공중에 들려 몸 앞쪽으로 뻗는 중
컷4: A쌍=가장 뒤에서 막 땅을 떼려 함 / B쌍=몸보다 가장 앞에서 막 땅에 닿음
컷5: A쌍=공중에 들려 몸 약간 뒤쪽에서 앞으로 나가는 중 / B쌍=몸 앞쪽에 딛고 있음
컷6: A쌍=공중에 들려 몸 앞쪽으로 뻗는 중 / B쌍=몸 약간 뒤쪽에 딛고 있음

몸과 꼬리: 머리를 높이 들고 앞을 봅니다. 걸음마다 몸통이 위아래로 살짝 통통 튑니다(컷4~컷1 사이가 가장 높음). 몸통은 거의 수평입니다.
꼬리는 6컷 모두 같은 모양과 같은 높이입니다: 엉덩이에서 위로 높이 세워지고 끝이 앞쪽으로 둥글게 휘어 있는 경쾌한 모양. 꼬리가 컷마다 바뀌면 안 됩니다.
귀는 앞으로 쫑긋 서 있습니다. 한 컷 안에서 땅을 딛는 발바닥은 모두 같은 바닥선 위에 있습니다.
```

- 6컷에서 **뒷다리 두 개가 모두** 컷마다 위치가 달라졌는가
- **꼬리**가 6컷 모두 같은 높이인가
- 고양이 크기, 머리 크기가 6컷에서 같은가
- 꼬리 끝과 귀가 칸 밖으로 잘리지 않았는가
- 6번째 컷과 1번째 컷이 자연스럽게 이어지는가

걷기(또는 살금살금)의 컷 N만 그려 주세요: [위 표의 컷 N 문장을 붙여 넣기]
