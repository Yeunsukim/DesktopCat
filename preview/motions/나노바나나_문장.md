# 나노 바나나에 넣을 문장

## 0. 먼저 알아 두기 (결과가 좋아지는 요령)

1. **기준 사진을 꼭 같이 첨부하세요.** 고양이 사진(`assets/cat_lying.png`)을 매번 첨부하고, 아래 "공통 앞부분"을 먼저 붙여 넣은 뒤 동작 문장을 이어 붙입니다.
2. **한 번에 6컷보다 한 컷씩 만드는 쪽이 고양이가 안 변합니다.** 6컷을 한 장에 요청하면 컷마다 얼굴·무늬가 조금씩 달라지기 쉽습니다. 그럴 때는 마음에 드는 첫 컷을 다시 첨부하고 "이 고양이와 똑같이, 다음 컷만 그려 주세요: 컷 2 ..."로 이어 가세요.
3. **참고 그림을 같이 올리면 자세가 더 정확합니다.** `preview/motions`의 해당 동작 줄(6컷)을 잘라서 두 번째 첨부로 올리고 "두 번째 그림은 자세와 순서만 참고하고, 고양이는 첫 번째 사진과 똑같이 그려 주세요"라고 적습니다. 참고 그림은 뼈대로 그린 근사치라서 실제 고양이와 다른 곳이 있으니 "관절 모양과 질감은 실제 고양이답게 바로잡아 주세요"도 덧붙이세요.
4. 컷마다 **발바닥 높이와 고양이 크기를 같게** 요청해 두었습니다. 프로그램에 쓰려면 이 조건이 중요합니다.
5. 결과의 배경은 나중에 지워야 합니다(흰 배경으로 받아서 배경 제거).

## 1. 공통 앞부분 (모든 동작 문장 맨 앞에 붙이기)

```
첨부한 사진 속 고양이와 완전히 같은 고양이를 그려 주세요. 갈색 줄무늬(태비) 털, 가슴과 배는 크림색, 연두빛 도는 갈색 눈, 분홍색 귀 안쪽, 털은 보송보송하고 사실적입니다.
사진처럼 실제로 찍은 듯한 사실적인 스타일로, 카메라는 고양이의 정확한 옆모습(고양이는 항상 화면 오른쪽을 봅니다), 고양이 눈높이에서 찍습니다.
배경은 깨끗한 흰색, 바닥에는 아주 얇고 옅은 그림자만 둡니다. 글자·로고·테두리·다른 물건은 넣지 않습니다.
모든 컷에서 고양이의 크기, 카메라 각도, 발바닥이 닿는 바닥 높이를 똑같이 유지합니다.
```
