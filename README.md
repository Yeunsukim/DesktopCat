# 바탕화면 고양이 키우기

바탕화면을 돌아다니고, 열린 창 위에 올라가고, 바탕화면 아이콘을 발로 차는 데스크톱 펫입니다.
고양이는 이미지 파일이 아니라 **뼈대(스켈레톤)로 매 프레임 그려서** 움직이고, 겉모습은 실사 고양이 사진에서 오려낸 머리·털·발을 입힙니다.

## 설치 (일반 사용자)

`build/dist/DesktopCat_Setup.exe` 하나만 실행하면 됩니다. 관리자 권한이 필요 없고, 내 계정 폴더(`%LOCALAPPDATA%\Programs\DesktopCat`)에 설치됩니다.

- 설치 창에서 **윈도우를 켤 때 자동 실행**(기본 켜짐), 시작 메뉴·바탕화면 바로가기, 설치 후 바로 실행을 고를 수 있습니다.
- 실행하면 작업 표시줄 오른쪽 아래(트레이)에 고양이 아이콘이 생깁니다. 윈도우 11은 새 아이콘을 `^`(숨겨진 아이콘) 칸에 넣으니, 항상 보이게 하려면 그 칸에서 작업 표시줄로 끌어다 놓으세요.
- 삭제는 **설정 → 앱**에서 "데스크탑 고양이"를 삭제하면 됩니다(고양이 기록을 지울지 물어봅니다).
- 이미 설치된 상태에서 다시 설치하면 실행 중인 고양이를 끄고 파일을 바꾼 뒤 다시 켭니다(업데이트).
- 설치 파일은 `python build_installer.py`로 다시 만들 수 있습니다(PyInstaller 필요). 서명이 없어서 윈도우가 "알 수 없는 게시자" 경고를 띄울 수 있습니다.

## 죽지 않게 하는 장치

고양이는 **지킴이**(`launcher.py`)와 **고양이 본체**(`cat.py`) 두 프로세스로 돌아갑니다.

- 본체가 갑자기 죽으면 지킴이가 몇 초 안에 다시 살립니다. 계속 바로 죽으면 대기 시간을 늘려(최대 5분) 컴퓨터를 괴롭히지 않으면서 계속 시도합니다.
- 본체는 5초마다 "살아 있다"는 신호를 보냅니다. 90초 넘게 신호가 없으면(응답 없음) 지킴이가 강제로 끄고 다시 켭니다. 절전에서 깨어난 직후에는 잠시 봐 줍니다.
- 본체는 화면 갱신 중 오류가 나도 꺼지지 않고, 메모리·GDI 개체·핸들이 새면 스스로 깔끔하게 껐다가 다시 켭니다. 탐색기가 다시 시작돼도 바탕화면 아이콘 연결을 되살립니다.
- 트레이의 **종료**를 누르면 지킴이도 같이 끝납니다. 작업 관리자에서 본체만 끄면 되살아납니다.
- 기록은 `%LOCALAPPDATA%\DesktopCat`에 있습니다: `pet_state.json`(배고픔·기분), `cat_guard.log`(지킴이가 되살린 기록), `cat_error.log`(오류). 로그는 20만 바이트가 넘으면 비워서 커지지 않습니다.

## 실행 (개발용)

```
pip install -r requirements.txt      # 처음 한 번
start_cat.bat                        # 콘솔 없이 지킴이로 실행 (본체만: python cat.py)
```

| 옵션 | 설명 |
|---|---|
| `--no-icons` | 아이콘 차기 끄기 (바탕화면 아이콘을 전혀 건드리지 않음) |
| `--scale 1.0` | 고양이 크기 (기본 0.8 = 예전 크기의 80%). 그리기, 속도, 점프 거리, 충돌 범위가 함께 바뀝니다 |
| `--skin cartoon` | 일러스트 모양으로 실행. 기본은 `sprite`(실제 고양이 사진 컷), `photo`는 사진 질감을 입힌 뼈대 고양이(예전 방식) |
| `--coat gray` | 털색: `brown`(갈색 줄무늬) `gray`(회색) `black`(검정) `white`(흰색) `orange`(치즈) `calico`(삼색). 평소에는 메뉴에서 고르고, 마지막으로 고른 색을 기억합니다 |
| `--quit` | 실행 중인 고양이와 지킴이를 정상 종료 (`DesktopCat.exe --quit` 또는 `python launcher.py --quit`) |
| `--low-priority` | 우선순위를 낮춰 CPU를 더 아낌 (대신 다른 프로그램이 바쁠 때 움직임이 끊길 수 있음) |

## 조작

- **클릭 → 앱 런처**: 고양이를 클릭하면 '몸 세우고 앉아 갸웃' 자세로 생각하는 척하고, 머리 위에 반원(아치) 모양 풍선이 열려 아이콘이 나옵니다.
  기본은 구글 캘린더·Gmail(브라우저로 열림)이고, 우클릭 메뉴 `➕ 앱 등록…`으로 프로그램(exe·바로가기)이나 웹 주소를 더하고 `🗑 등록한 앱 지우기`로 뺄 수 있습니다(7개를 넘으면 양 끝 화살표로 쪽 넘김).
  아이콘을 누르면 실행되고 풍선이 닫힙니다. 고양이를 다시 클릭 / 바깥 클릭 / Esc / 8초 동안 마우스가 아치 위에 없으면 닫힙니다. 등록한 앱은 데이터 폴더의 `launcher_config.json`에 저장됩니다.
- **쓰다듬기**: 마우스를 고양이 몸 위에서 쓱쓱 움직이면(클릭이 아니라) → 골골골, 눈을 감고 엉덩이를 치켜듭니다
- **집어 올리기**: 고양이를 드래그해서 놓으면 떨어집니다 (놓는 속도로 던질 수도 있어요)
- **메뉴**: 고양이 우클릭 또는 트레이 아이콘 우클릭 → 밥 주기 / 놀아주기 / **고양이 색(갈색 줄무늬·회색·검은색·흰색·치즈·삼색)** / **앱 등록·등록한 앱 지우기** / 아이콘 차기 켜기·끄기 / 아이콘 원래대로 / 종료
- 배고픔·기분은 시간이 지나며 변하고 행동에 영향을 줍니다. `pet_state.json`에 저장됩니다.

| 잠자기 | 동그랗게 말고 자기 / 옆으로 누워 자기 / 식빵으로 턱 괴고 자기 / 앉아서 꾸벅꾸벅 |

## 실제 고양이 사진으로 움직이기 (기본)

동작 하나마다 사진 6컷(꾹꾹이는 9컷, 살금살금은 7컷)을 연속 동작으로 만들어 두고, 고양이가 그 동작을 하는 동안 컷을 넘겨 가며 보여 줍니다.
걷기·달리기는 **이동한 거리**에 맞춰 컷이 넘어가서 발이 미끄러지지 않고, 몸통은 컷이 바뀌어도 제자리(발바닥 높이와 몸 무게중심 기준)에 있습니다.
컷 사이 자세 차이가 큰 동작은 컷을 선명하게 보여 주다가 바뀌는 순간에만 빠르게 섞어서 잔상(두 마리처럼 보임)이 생기지 않게 했습니다.
아쉬운 점은 컷이 6장뿐이라 뼈대 방식보다 **움직임이 덜 매끈**하다는 것입니다. 공·밥그릇·방석은 사진에 없어서 그려서 얹습니다.

**자연스러운 움직임**
- 걷기·달리기는 약 0.35초에 걸쳐 빨라지고, 걷기가 끝나면 서서히 느려져 멈춘 뒤 다음 행동을 합니다(한 번에 서지 않음). 걸음 위상이 이동 거리를 따르므로 속도를 바꿔도 발이 미끄러지지 않습니다.
- 걷다가 화면·창 끝에 닿으면 걷던 자세 그대로 뒤집지 않고, 멈춰 서서 돌아섭니다. 같은 자세에서 방향만 바뀌어도 거울처럼 확 뒤집지 않고 서서히 바뀝니다.
- 서 있기·앉기·갸웃·식빵 자세는 짧은 영상을 앞뒤로 되감듯 반복하지 않고, 1~4초 가만히 있다가 가끔 이웃 컷으로 천천히 옮겨 갑니다.
- 바닥(작업 표시줄 윗변·창 윗변)에 발을 딱 맞추면 오히려 떠 보여서, 발을 2.5픽셀 걸쳐 그립니다. 옆으로 누운 자세처럼 뻗은 발끝보다 몸이 위에 있는 자세는 몸 아랫선이 바닥에 닿도록 더 내립니다(동작별 값은 `tools/frame_gaps.py`가 `sprites.json`의 `rest`로 잼). 작업 표시줄이 없는 화면 맨 아래에서는 내리지 않습니다.
- 사용자가 작업 표시줄을 누르면 작업 표시줄이 고양이보다 앞으로 오므로, 끌고 다닐 때와 앞 창이 바뀔 때 고양이를 다시 맨 앞으로 올립니다(시작 메뉴·검색·작업 표시줄 메뉴가 떠 있을 때는 가리지 않게 올리지 않음).

**또렷한 눈**: 털색을 바꾸면 노란 홍채까지 털로 칠해져 검은·흰·삼색 고양이의 눈이 안 보였습니다. `tools/eye_marks.py`가 컷마다 눈 위치를 찾아 `sprites.json`에 넣고(동작 첫 컷에서 사람이 찍은 눈을 따라가고, 잘 찾은 눈 조각을 견본 삼아 나머지 컷에서도 찾음, 331컷 중 눈을 뜬 220컷), 앱은 그 자리에 털색과 상관없이 같은 연두빛 노란 홍채·동공·반짝임을 그립니다(`coats.paint_eyes`).
컷 만드는 순서(개발용, Pillow·numpy·scipy 필요):

1. `preview/ai_motions/`에 동작마다 흰 배경 위의 6컷 그림(이미지 생성 AI로 만든 것)을 둡니다. 이름은 `분류번호-분류-동작.png` 형식입니다.
2. `python tools/slice_ai.py` — 컷을 자르고 배경을 지웁니다. 흰 배경은 "완전히 흰색이고 넓게 이어진 영역"만 지우고(연한 털은 남김),
   경계 몇 픽셀에서만 흰색이 섞인 정도를 계산해 투명도로 바꾸며, 원본이 흐릿할수록 경계를 더 넓게 부드럽게 처리합니다. 결과는 `assets/ai/`, 확인 그림은 `preview/ai_cut/`.
   칸 가장자리에서 잘린 컷은 목록으로 알려 줍니다(그림을 다시 받아야 할 컷).
3. `python tools/build_sprites.py --chart` — 크기와 색을 맞춰 `assets/sprites/`를 만듭니다. 같은 고양이로 보이게 **귀 안쪽 분홍색 크기**로 확대율을 정하고
   (서 있는 고양이가 뼈대 고양이와 같은 높이가 되게), 귀가 가려지는 동작은 `EAR_FIX`로 손보정합니다. 털색도 전체 평균에 맞춥니다. 확인 그림은 `preview/sprite_chart.png`.
4. `python tools/ai_player.py` — 모든 동작을 반복 재생해 보는 `preview/ai_player.html`을 만듭니다.
5. 컷을 새로 만들면 `build_sprites.py`가 끝에서 `frame_gaps.py`(컷 사이 차이·누운 자세 몸 아랫선)와 `eye_marks.py`(눈 위치)를 자동으로 부릅니다. 눈 위치 확인 그림: `python tools/eye_marks.py 폴더`.

### 털색 바꾸기

메뉴의 "🎨 고양이 색"에서 고릅니다(바로 바뀌고 다음 실행에도 유지). 눈·코·귀 안쪽·혀는 색이 바뀌지 않고, 줄무늬와 털결은 그대로 남습니다.
검은색·회색·흰색·치즈는 밝기에 색 띠(그라데이션)를 입히는 방식이고, 삼색은 흰 바탕에 주황·검정 얼룩을 올립니다. 새 털색은 `coats.py`의 `COATS`와 `_RAMPS`에 추가하면 메뉴에 나타납니다.
사진을 못 불러오면 자동으로 예전 뼈대 고양이로 실행됩니다.

- **런처 반원**: 아이콘 사이가 넉넉해지도록 반원을 키웠고(반지름 74 → 98, 아이콘 지름 32), 기본 아이콘은 **캘린더·Gmail·Google·YouTube** 네 개입니다. 아이콘은 모두 굵은 윤곽선의 귀여운 스티커 그림이고,
  **웹 주소는 그 사이트의 파비콘**(없으면 귀여운 지구본)을, 프로그램은 윈도우 아이콘을 동그란 스티커 안에 넣어 보여 줍니다. 파비콘은 등록하거나 켤 때 백그라운드로 받아 `icons` 폴더에 보관합니다(실패하면 3일 뒤에 다시).
- **앱 등록**: 프로그램·파일 / 웹 주소 / **명령 실행**(cmd 또는 PowerShell 창을 열고 명령을 쳐 줌, 창 유지 선택) / **윈도우 도구**(제어판, 윈도우 설정, 장치 관리자, 작업 관리자, 프로그램 및 기능 등 19개 목록)를 등록할 수 있습니다.
- **발바닥 접지**: 컷마다 발바닥 아래의 빈 줄을 재서 발이 바닥선에 딱 닿게 내려 그립니다(평균 1.4px, 최대 4px). 그림자도 조금 진하게 했습니다.

## 하루 생활 (행동 비율 · 자연스러운 흐름 · 잠 · 밥 · 놀아주기 · 한쪽에서 쉬기)

**시간 배분**: 집고양이는 하루의 약 60%를 자고 약 25%를 쉬며(합쳐 85% 안팎), 이동·놀이·그루밍·먹기는 각각 한 자릿수~10%대만 차지한다는 연구·수의 자료를 따랐습니다
(자료마다 수치가 달라서 평균적인 값을 골랐습니다). 이 고양이의 목표 비율은 다음과 같습니다.

| | 깨어 있는 낮 시간 | 하루 전체(밤 잠 22~07시 포함) |
|---|---|---|
| 잠(낮잠) | 36% | **60%** |
| 쉬기(앉기·서 있기·식빵) | 32% | 20% |
| 그루밍·긁기 | 13% | 8% |
| 이동(걷기·종종걸음·살금·달리기·점프) | 8% | **5%** |
| 놀이(꾹꾹이·꼬리 놀이·아이콘 차기) | 6% | 4% |
| 하품·기지개 | 3% | 2% |

예전에는 이동이 15%, 놀이 6%였습니다. 시간대도 반영해서 아침(7~10시)·저녁(17~21시)에는 조금 더 활발하고 한낮(11~16시)에는 낮잠이 늡니다.
`python tools/sim_behavior.py` 로 하루치를 화면 없이 시뮬레이션해서 실제 비율을 잴 수 있고, 비율 값은 `flow.py` 의 `TARGET_DAY` 에서 바꿉니다
(바꾼 뒤 `python tools/test_flow.py --print` 로 새 가중치를 뽑아 `flow.py` 에 붙여 넣으면 됩니다).

**자연스러운 흐름**: 행동을 아무렇게나 고르지 않고 `flow.py` 의 FLOW 표대로 이어 붙입니다. 예: 달리기 → 걷기·서 있기·그루밍(곧장 눕지 않음), 살금살금 → 덮치기·달리기,
꾹꾹이 → 식빵 → 잠, 잠 → 하품·기지개 → 앉기, 먹기 → 세수 → 앉기·식빵·낮잠, 놀기 → 숨 고르기. 시뮬레이션 4,600번의 전환 중 흐름에 없는 전환은 0번입니다(`tools/test_flow.py`).

**🛌 한쪽에서 쉬기**: 우클릭 메뉴에서 켜면 고양이가 화면 구석(설정에서 오른쪽/왼쪽 선택)으로 가서 돌아다니지 않고 잠·식빵·그루밍만 합니다(잠 54%, 쉬기 28%, 그루밍 12%…). 다시 끄면 돌아다닙니다.
쉬는 중에도 아래 '놀아주기' 간격(기본 1시간)이 되면 구석에서 나와 놀아 달라고 합니다.

**🧶 놀아주기 요구**: 마지막으로 놀아 준 뒤 60분(설정에서 10~240분)이 지나면 풍선 `놀아줘라옹~`과 `냐옹~ 냐옹~` 소리로 졸라댑니다. 풍선이나 메뉴 '놀아주기'를 누르면 놀고, 안 놀아 주면 3분마다 되풀이(최대 10번)합니다.

**🍚 밥 시간(하루 세 번, 기본 08:00 · 13:00 · 19:00)**: 시간이 지났는데 밥을 안 주면 `밥 줘라옹~` 풍선과 `냐옹~ 냐옹~` 소리로 3분마다 졸라댑니다(최대 10번, 다음 밥 시간·잠자는 시간에 끝남).
풍선이나 메뉴 '밥 주기'를 누르면 먹고(밥 시간에는 배가 불러도 먹음) 멈춥니다. 밥 시간 30분 전부터 준 밥은 그 끼니로 칩니다. 배고픔은 끼니 사이 약 5시간에 걸쳐 쌓이도록 조정했습니다.

**😴 잠자는 시간(기본 22:00~07:00)**: 고양이는 구석으로 가서 웅크리고 잡니다(쓰다듬어 깨워도 곧 다시 잠). 이 시간에는 일정·소식·어제 한 일 같은 **정해 둔 알림도, 밥·놀아주기 졸라대기도 하지 않습니다**
(깨어난 뒤 놓친 알림은 가장 최근 것 하나만 알려 줍니다. '지금 시험'과 활동 기록은 계속 동작합니다). 아침에 깨면 하품·기지개부터 합니다.

설정: 우클릭 메뉴 → **⚙ 설정… → 🐾 생활**(잠자는 시간, 밥 시간 3개, 놀아 달라는 간격, 쉬는 구석). 새 파일: `flow.py`(흐름·비율) `routine.py`(잠·밥·놀이 요구) `tools/sim_behavior.py` `tools/test_flow.py` `tools/test_routine.py` `tools/test_modes.py`.

## 캘린더 알림 (오늘 일정을 풍선으로)

정해 둔 시각에 고양이가 "냐옹~" 소리와 함께 머리 위 풍선으로 오늘 구글 캘린더 일정을 알려 줍니다(종일 일정 먼저, 시각순, 6개 이상이면 "… 외 N개").
풍선은 글 길이에 따라 8~20초 뒤 사라지고, 마우스를 올려 두면 안 사라지며, 클릭하면 구글 캘린더가 열립니다.

설정: 우클릭 메뉴 → **⚙ 설정… → 📅 캘린더**
1. 구글 캘린더 → 설정 → '내 캘린더의 설정' → '캘린더 통합'의 **iCal 형식의 비공개 주소**를 복사해서 붙여 넣습니다(구글 로그인 불필요, 읽기 전용).
   이 주소는 캘린더 전체를 읽을 수 있는 비밀 값이라 화면에 가려지고, **윈도우 계정으로 암호화**(DPAPI)해서 `secrets.json`에 저장합니다(설정 파일에는 평문으로 남지 않습니다).
2. '알림 시각'에 하루에 알릴 시각을 여러 개 추가합니다(기본 09:00). `🐾 지금 시험해 보기`로 바로 확인할 수 있습니다.
- 컴퓨터가 꺼져 있어서 시각을 놓쳤으면 켠 뒤 처음 점검 때 **그날 놓친 알림 중 가장 최근 것 하나**만 따라잡습니다. 같은 시각의 알림은 한 번만 울립니다(`launcher_config.json`의 `last_run`).
- 주소가 없으면 정해진 시각에는 조용히 넘어가고, '지금 시험'에서만 안내합니다. 네트워크가 안 되거나 주소가 틀리면 풍선으로 이유를 알려 줍니다(주소는 메시지·로그에 넣지 않습니다).
- 일정은 읽기만 합니다. 등록은 런처의 캘린더 아이콘(웹)에서 하세요.
- 소리는 `assets/meow.wav`가 있으면 그것을, 없으면 합성한 울음소리를 씁니다. 진짜 고양이 소리 wav 를 그 이름으로 넣으면 바뀝니다.
- 네트워크 호출은 모두 별도 스레드에서 하고(타임아웃 10초) 고양이 화면을 멈추지 않습니다. 새 파일: `calendar_ics.py` `scheduler.py` `balloon.py` `catsound.py` `settings_dialog.py` `config_store.py`.

## 정해 둔 알림이 빠지지 않게 하는 규칙 (캘린더·소식·어제 한 일·매시 알림 공통)

- **자리를 비웠거나 전체 화면 앱이 떠 있어도** 알림 작업은 제 시각에 돕니다(고양이가 멈춰 있어도 점검은 계속). 그 사이 도착한 결과는 풍선이 아무도 못 보고 사라지지 않게 붙잡아 두었다가, **돌아오면 고양이가 나타난 뒤 차례로** 보여 줍니다(매시 알림이 여러 번 쌓이면 새 메일은 모두, 일정은 가장 최근 것으로 합침).
- 컴퓨터를 켜거나 잠에서 깬 **직후에는 인터넷이 아직 안 붙었을 수** 있습니다. 일시적인 오류(연결 실패·시간 초과·서버 바쁨)면 오류 풍선 대신 **1분·3분·10분 뒤에 조용히 다시** 해 보고, 끝내 안 될 때만 알려 줍니다(오류 기록: `cat_error.log`). 매시 알림은 실패한 부분(일정/메일)만 다시 합니다.
- 놓친 정각은 켠 직후에 바로 따라잡습니다(일일 알림은 오늘 놓친 것 중 가장 최근 것 하나, 매시 알림은 3시간 안). 잠자는 시간(22~07시)에는 쉬고 깬 뒤 하나만 알립니다.
- 설정 창에서 저장만 했다고 놓친 알림이 사라지지 않습니다. **시각이나 켜짐을 바꾼 알림만** 그 시점 이전 시각을 ‘한 것’으로 칩니다.
- 시험: `tools/test_scheduler_rules.py`(규칙), 실제 앱으로 자리 비움·인터넷 지연을 흉내 내 보는 시험은 개발 중 확인했습니다.

## 매시 정각 알림 (앞으로 2시간 일정 + 새 Gmail)

**일정**: 정각(8:00, 9:00 …)마다 캘린더를 읽어서 **그 시각부터 앞으로 N시간(기본 2시간) 안의 일정**만 풍선으로 알립니다. 예: 8시 정각에는 8~10시 일정만.
이미 시작해서 진행 중인 일정도 `(진행 중)`으로 함께 보여 주고, 종일 일정·취소된 일정은 제외합니다. 일정이 없으면 조용히 넘어가며, 같은 정각에 '오늘 일정' 알림이 나갔으면 한 번만 알립니다.
**메일**: 정각마다 새 메일이 있으면 풍선 `홍길동에게서 메일 왔다~옹~ 📧`(여러 명이면 `홍길동 외 2명에게서 …`)을 띄웁니다.
- 정각을 놓쳤으면(컴퓨터를 켠 시각이 정각에서 20분 넘게 지났으면) 따라잡지 않고 다음 정각을 기다립니다. 잠자는 시간에는 쉽니다.
- 여러 알림이 한꺼번에 오면 풍선이 서로 덮어쓰지 않고 앞의 것이 닫힌 뒤 차례로 나옵니다.
- 설정: **⚙ 설정… → 📅 캘린더 → ⏰ 매시 정각 알림**(켜기, 앞으로 몇 시간) / **📧 메일**(Gmail 연결, 켜기). 각각 `지금 확인해 보기` 버튼이 있습니다.

**Gmail은 어떻게 읽나**: 구글 로그인 창이나 개발자 등록 없이, 구글 계정의 **앱 비밀번호**(2단계 인증을 켠 뒤 [여기](https://myaccount.google.com/apppasswords)에서 발급)로 IMAP(imap.gmail.com, 암호화)에 접속합니다.
- 읽는 것은 **안 읽은 메일의 '보낸 사람' 이름뿐**입니다. 제목·본문은 가져오지 않고, 메일을 '읽음'으로 바꾸거나 지우거나 보내지 않습니다(읽기 전용으로 열고 BODY.PEEK 사용).
- 앱 비밀번호는 내 메일함에 들어갈 수 있는 열쇠라서 **윈도우 계정으로 암호화**(DPAPI)해 `secrets.json`에 저장합니다. 처음 확인할 때는 기준점만 잡고 안 읽은 메일 개수만 알려 주며, 그 뒤에 온 메일만 알립니다.
- 구글 워크스페이스(회사·학교) 계정은 관리자가 앱 비밀번호를 막아 두었을 수 있습니다.
- 새 파일: `mail_imap.py`. 일정 읽기는 `calendar_ics.py`(`events_between`)에 추가했습니다.

**말투**: 고양이 말투(~냥, ~옹)는 고양이의 혼잣말·알림·설정 안내에만 씁니다. **뉴스·날씨·주식 같은 외부 정보 본문은 담백한 존댓말**로 정리합니다(`gemini_client.SYSTEM_PLAIN`). 어제 한 일 요약은 내 기록이라 고양이 말투를 씁니다.

**자리 비움(유휴) 기준**: ① 고양이 그리기를 멈추는 기준은 **10분**(`cat.py`의 `AWAY_SECONDS = 600`) — 이때는 알림 점검도 멈추고 돌아오면 이어서 합니다. ② 활동 기록에서 시간을 세지 않는 기준은 **5분**(`activity_log.py`의 `IDLE_STOP = 300`).

## 소식 알림 (날씨·뉴스·시세를 Gemini가 정리)

정해 둔 시각에 고양이가 "냐옹~" 소리와 함께 풍선 `소식왔다~옹~ 📰`을 띄우고, **새 창**에 오늘의 날씨·주요 뉴스·시세를 ~냥/~옹 말투로 정리해서 보여 줍니다
(풍선을 누르면 창이 앞으로 나옵니다). 창 아래에는 "AI가 정리한 내용이라 틀릴 수 있고 투자 조언이 아니다"라는 안내가 항상 보입니다.

**어떻게 모으나:** 무료 Gemini 키는 '구글 검색' 도구가 막혀 있어서(검색을 켠 호출만 "한도 초과"로 거절됨), 고양이가 자료를 **직접 모으고 Gemini에게는 정리만** 시킵니다.
- 날씨: Open-Meteo(키 불필요). 지역은 기본 **'자동'** = 이 컴퓨터의 IP 주소를 위치 조회 서비스(ipwho.is → geojs.io → ipapi.co 순서)에 보내서 대략 어느 동네인지만 알아냅니다. 설정에서 주요 도시를 직접 고를 수도 있습니다.
- 뉴스: Google 뉴스 RSS 한국 주요 기사 12개(소식 창 아래에 원문 링크 10개). 시세: Yahoo Finance 차트 주소(코스피·코스닥·나스닥·원/달러, 설정에서 `이름=심볼` 줄로 바꿈).
- 자료 하나가 실패해도 나머지로 정리하고, 전부 실패하면 오류를 알려 줍니다. 유료 키는 설정에서 'Gemini의 구글 검색 사용'을 켜서 예전 방식(검색)을 쓸 수 있습니다.

설정: 우클릭 메뉴 → **⚙ 설정… → 📰 소식**
1. [Google AI Studio](https://aistudio.google.com/apikey)에서 받은 **Gemini API 키**를 붙여 넣습니다. 키는 화면에 가려지고 **윈도우 계정으로 암호화**(DPAPI)해서 저장합니다(설정 파일·로그·명령줄에는 남지 않습니다). `🔌 연결 시험`으로 키가 되는지 먼저 봅니다.
2. **프롬프트**(정리 방법)를 마음대로 고칠 수 있습니다. 기본값은 날씨, 주요 뉴스 5개, 시세 등락 한 줄씩입니다. `기본값으로 되돌리기`로 복구합니다.
3. **모델**은 비워 두면 `gemini-3.5-flash-lite`를 씁니다. 모델 이름이 바뀌면 여기서 고치세요.
4. 알림 시각(기본 08:00)을 추가하고 `🐾 지금 시험해 보기`로 확인합니다.
- 서버가 바쁘거나(429/503) 인터넷이 잠깐 끊긴 경우는 조용히 10분 뒤 다시 해 보고(최대 2번), 그래도 안 되면 풍선으로 이유를 알려 줍니다. 키가 틀렸거나 사용 한도에 걸린 경우는 바로 알려 줍니다.

- **전송되는 것**: 프롬프트와 모아 온 자료(날씨·뉴스 제목·시세)가 구글로 갑니다. 위치 조회 때 IP 주소가 조회 서비스로 갑니다('자동'일 때만).

## 어제 한 일 (활동 기록 + AI 요약)

컴퓨터에서 **어떤 프로그램을 얼마나 썼는지**(+ 창 제목)를 하루 단위로 기록해 두었다가, 정해 둔 시각(기본 09:30)에 풍선 `어제 한일이다~ 냐옹~ 🕘`과 함께 Gemini가 정리한 요약을 새 창에 보여 줍니다.
**어제가 아니라 최근 30일 중 원하는 날**도 골라서 볼 수 있습니다. 기록이 없는 날은 알림을 띄우지 않습니다.

설정: 우클릭 메뉴 → **⚙ 설정… → 🕘 어제 한 일**
1. `컴퓨터에서 쓴 프로그램과 창 제목을 기록하기`를 켭니다. **기본은 꺼짐**이고, 처음 켤 때 무엇이 저장되고 어디로 가는지 설명하는 동의 창이 뜹니다.
2. **지난 기록 보기**에서 날짜를 고르면(최근 순, 어제 표시와 그날 총 사용 시간이 함께 보임)
   - `🤖 AI 요약 보기`: 그날 기록을 Gemini가 정리(Gemini 키는 소식 탭에서 입력한 것을 씁니다)
   - `📋 기록 그대로 보기`: AI에게 보내지 않고 이 컴퓨터의 기록만 프로그램별 시간·창 제목으로 보여 줍니다
3. `정해 둔 시각에 어제 한 일 알려 주기`를 켜고 시각·프롬프트(정리 방법)를 정합니다.

**무엇을 기록하나**
- 프로그램 이름 + 창 제목 + 쓴 시간(초)뿐입니다. **키보드로 친 내용·화면 내용은 기록하지 않습니다.**
- 5초마다 맨 앞 창을 한 번 봅니다(1회 0.001ms 수준). 5분 넘게 입력이 없거나 화면이 잠긴 시간, 고양이 자신의 창은 세지 않습니다.
- 시크릿/InPrivate 창, 암호 관리자, 은행·인증서 관련 창, 그리고 설정에서 정한 단어가 들어간 창은 `(제외됨)`으로만 기록합니다.
- 파일: `데이터폴더\activity\YYYY-MM-DD.json` = `{프로그램: {창 제목: 초}}`. 60초마다 저장(임시 파일 → 바꿔치기)하고 **30일이 지난 파일은 자동 삭제**합니다. `📂 기록 폴더 열기`, `기록 모두 지우기` 버튼이 있습니다.
- **구글로 가는 것**: 'AI 요약'을 만들 때 그날의 프로그램 이름·창 제목 요약이 Gemini로 전송됩니다(무료 등급은 구글이 서비스 개선에 쓸 수 있다고 안내돼 있음). '기록 그대로 보기'는 어디로도 보내지 않습니다.
- 새 파일: `activity_log.py`. 설치 파일의 삭제 프로그램은 `--purge` 때 데이터 폴더와 함께 이 기록도 지웁니다.

## 경비 고양이 (랜섬웨어·스파이웨어 같은 '쥐'를 알아채서 알려 주기)

고양이가 **수상한 행동을 일찍 알아채서 알려 주는 경비원**이 됩니다. 경보가 위험 단계면 쥐가 나타나고 고양이가 달려가 잡는 모습과 함께 풍선·소리·상세 창이 뜹니다.

**⚠ 백신이 아닙니다.** 파일 내용을 검사해 악성코드를 가려내는 일은 하지 않으므로 알약·Windows 보안 같은 백신을 대신하지 못합니다. 백신이 놓칠 수 있는 '행동' 단서를 보고 "수상해요"라고 알려 줄 뿐이며, 이미 암호화된 파일을 되살리거나 암호화를 막지는 못합니다.
**자동으로 지우거나 끄거나 막지 않습니다.** 알림 창의 버튼을 사용자가 직접 누를 때만 조치합니다: `위치 열기` · `의심 프로그램 종료`(확인 창, 시스템 핵심 프로세스는 버튼 숨김) · `허용`(다음부터 알리지 않음) · `무시`.

| 감시 | 방법 | 파일 |
|---|---|---|
| 랜섬웨어 | 문서·사진·다운로드 등을 지켜보다가 ① 미끼 파일이 바뀌거나 ② 짧은 시간에 여러 폴더의 파일이 한꺼번에 낯선 확장자/무작위 데이터(엔트로피)로 바뀌거나 ③ 몸값 안내 파일 이름이 생기면 경보. 경보 순간 쓰기가 많은 프로세스를 '후보'로 보여 줌(확정 아님) | `sec_ransom.py` `sec_watch.py` |
| 자동 시작·실행 중 프로그램 | 10분마다(보조 프로세스) 새 자동 시작 항목·예약 작업·서비스, 임시/AppData/다운로드 폴더에서 도는 서명 없는 프로그램, 시스템 프로세스 이름 흉내, 이중 확장자를 점수로 매김 | `sec_scan.py` `sec_sig.py` |
| 카메라·마이크 | 윈도우의 '마이크·카메라 사용 기록'을 읽어, 처음 보는 프로그램이 쓰는 중이면 알림(허용하면 기억) | `sec_privacy.py` |
| 다운로드 | 다운로드 폴더에 새로 받아진 실행 파일·스크립트·바로가기를 '인터넷에서 받음' 표시·디지털 서명·이중 확장자로 확인 (받기 시작할 때 생기는 0바이트 빈 자리 파일은 건너뜀) | `sec_download.py` |
| VirusTotal (선택) | 서명이 유효하지 않은 수상한 파일의 **SHA-256 해시값만** 조회(파일 내용·이름·경로는 보내지 않음). 무료 한도(분당 4건·하루 500건)를 지키고 결과는 30일 보관. '정보 없음'은 안전하다는 뜻이 아님 | `vt_client.py` |

**미끼 파일 (숨김 가짜 문서)**: 랜섬웨어를 가장 빨리 알아채려고 문서·사진·다운로드 폴더 맨 앞·맨 뒤에 `!_고양이미끼_회의록.docx` · `~_고양이미끼_견적서.docx` 같은 숨김 파일을 둡니다(바탕화면에는 두지 않음). 사람이 열 일이 없는 파일이라 바뀌면 곧바로 경보를 울립니다. 설정 → 경비 → `미끼 파일 모두 지우기`로 언제든 지울 수 있고(미끼 파일만 지움), `숨김 미끼 파일 사용`을 끄면 만들지 않습니다. 삭제 프로그램도 기록을 남기는 삭제에서 미끼 파일을 항상 함께 치웁니다.

**설정**: 우클릭 메뉴 → 설정… → **경비** 탭. 기능별 켜기/끄기, 민감도(느슨·보통·엄격), 점검 간격, `지금 점검`, 허용 목록, 잡은 쥐 기록(최근 30일), VirusTotal 키(Windows 계정으로 암호화 저장되며 로그·화면에 남지 않음), `시험 경보`(가짜 경보로 연출·창을 확인).
**데이터**: `데이터폴더\security\` (events.json 사건 기록 30일, 점검 기준 목록, VirusTotal 보관 결과). 삭제 프로그램은 `--purge` 때 함께 지웁니다.
**자원**: 폴더 감시는 윈도우의 변경 알림(ReadDirectoryChangesW)을 직접 받는 방식(`sec_watch.py`)이라 파일 변화가 없으면 CPU를 쓰지 않습니다. 파일 2만 개를 한꺼번에 풀고 고치고 지우는(사건 약 10만 개) 동안에도 코어 1개의 약 4%입니다(예전 watchdog 방식은 같은 상황에서 약 70%). 사건이 너무 많아 윈도우가 일부를 버리면 미끼 파일을 직접 확인해서 놓치지 않습니다.
무거운 점검(서명 확인 등)은 짧게 살다 사라지는 보조 프로세스에서 합니다. 10분마다 하는 점검은 보통 0.5초 남짓이고, 예약 작업·서비스 목록은 레지스트리 지문이 바뀌었거나 6시간이 지났을 때만 PowerShell로 새로 읽습니다(그때만 CPU 약 3초·메모리 100MB를 몇 초 동안 씁니다).

**시험(진짜 악성코드는 쓰지 않음)**: `python -I -X utf8 tools/test_ransom_sim.py`(임시 폴더에서 랜섬웨어를 흉내 낸 암호화 vs 압축 풀기·git·복사·사진 변환 같은 정상 작업) · `tools/test_security.py` · `tools/test_security2.py`(점검·카메라/마이크·다운로드·VirusTotal 가짜 서버).

## 사진 스킨 바꾸기 (예전 뼈대 방식: `--skin photo`)

다른 고양이 사진으로 바꾸려면 흰 배경의 사진을 `assets/cat_lying.png`로 두고 `pip install pillow numpy scipy` 후
`python tools/make_skin.py`를 실행하세요. 머리·눈·입·털 위치는 `make_skin.py` 위쪽 상수(`HEAD_CENTER`, `EYES_ORIG` 등)가
사진 기준이라, 사진이 바뀌면 이 좌표도 새 사진에 맞게 고쳐야 합니다.
`make_skin.py`는 사진에서 다음을 오려냅니다. 귀 두 개(밑동을 기준으로 뒤로 눕고 앞으로 서는 귀), 귀를 뺀 머리,
눈 위 털로 만든 눈꺼풀, 앞발, 그리고 몸통·다리 털 질감입니다. 몸통 털은 사진의 털 조각 수천 개를 불규칙하게 겹쳐 붙인 뒤
줄무늬를 손으로 그려 넣어서, 같은 무늬가 반복되지 않습니다.
눈 감기·하품 같은 표정은 머리 사진 위에 눈꺼풀을 덧그리고, **턱을 따로 오려서 입을 벌릴 때 실제로 내려가게** 해서 만듭니다.
벌어진 틈으로 입속(윗송곳니, 혀)이 보이고, 핥을 때는 혀가 턱 위로 늘어집니다.
몸·다리에는 윤곽선이 없고, 털 질감에 굵은 털결을 촘촘히 그려 넣었으며(2배 해상도), 가장자리에도 잔털을 그려 보송하게 보이게 합니다.
머리 크기와 목 길이는 `catrig.py`의 `Skin.head_scale`(0.85), `Skin.neck_k`(0.95)로, 발 크기는 `Skin`의 `paw_w/paw_h`(×0.9)로 조절합니다.
몸·다리·꼬리는 윤곽을 털색으로 한 겹 부풀려 수북하게 보이게 하고, 앞다리 위쪽은 몸통 털 속으로 서서히 스며들게 해서
흰 가슴에서 갈색 다리로 이어지는 부분에 이음선이 생기지 않습니다. 말풍선은 머리 바로 위에 붙어서 따라다닙니다.

자원을 아끼려고 다음을 합니다.

- 움직일 때는 초당 24번(**정밀 타이머로 간격을 고르게 유지**해서 부드럽게), 쉴 때는 8번, 잘 때는 5번만 그립니다.
- 움직이는 동안에는 눈에 잘 안 띄는 가장자리 잔털과 부드러운 그림자를 생략하고, 멈추면 다시 그립니다(그리는 비용이 약 30% 줄어듭니다).
- `--low-priority`로 실행하면 우선순위를 낮추고 윈도우 효율성 모드로 돌려서 CPU를 더 아낍니다. 대신 다른 프로그램이 바쁠 때 고양이가 몇백 ms씩 멈춰서 걸음이 끊길 수 있어 기본은 꺼 두었습니다.
- **전체 화면 앱**(게임·동영상 등 제목 표시줄 없는 창)이 고양이가 있는 모니터를 덮으면 고양이를 숨기고 멈춥니다. 끝나면 이어서 놉니다.
- **10분 넘게 키보드·마우스 입력이 없으면** 그리기를 멈춥니다. 돌아오면 이어서 놉니다.
- 위 두 가지를 끄려면 `--no-autopause`로 실행하세요.
- Qt 글꼴 엔진을 가벼운 GDI로 지정했습니다(기본 엔진은 메모리 약 70MB와 핸들 약 800개를 더 씁니다. 컬러 이모지는 그대로 나옵니다).
- 비정상 종료가 의심되면 `cat_crash.log`(Qt 내부 오류)와 `cat_error.log`(파이썬 오류)를 확인하세요. 둘 다 비어 있으면 오류가 없는 것입니다.

## 모니터가 여러 개일 때

보조 모니터가 있으면 고양이가 모든 모니터를 돌아다닙니다. 바닥 높이가 같은 모니터끼리는 하나의 긴 바닥처럼 걸어서 오가고,
"다른 모니터로 놀러 가기"(종종걸음)를 가끔 합니다. 보조 모니터에 있는 창 위에도 올라가고, 보조 모니터의 바탕화면 아이콘도 찹니다.
모니터를 연결하거나 빼거나 해상도를 바꾸면 자동으로 따라가고, 고양이가 사라진 화면에 있었다면 가까운 모니터 바닥으로 데려옵니다.

- **높이가 다른 모니터**(해상도가 달라 작업 영역 아래쪽이 다른 경우)는 맞닿은 가장자리에서 뛰어내리거나 뛰어올라 건너갑니다.
- **한계:** 모니터마다 화면 배율이 다르면 보조 모니터에서 위치가 어긋날 수 있어서 시작할 때 알려 줍니다.
  모니터를 위아래로 쌓은 배치는 주 모니터에서만 돌아다닙니다.

## 몸통

몸통은 등선과 배선이 따로 휘는 부드러운 곡선입니다. 등은 다리를 뻗고 모으는 정도에 따라 펴지고 굽으며(`hump`),
배는 가운데가 아래로 늘어집니다(`sag`). 자세별 값은 `animations.py`의 `BODY_FEEL`에서 정합니다(앉거나 누우면 배가 더 처지고, 달릴 때는 팽팽해집니다).
배 아래와 가슴에는 늘어진 긴 털이 따로 그려집니다.

## 꼬리

꼬리는 12마디의 스프링 사슬로 시뮬레이션합니다. 밑동이 움직이면 끝으로 갈수록 늦게 따라오며 휘고,
굵기는 끝으로 갈수록 가늘어집니다. 움직임은 고양이처럼 **몇 초마다 한 번, 1~2초에 한 번 왔다 갔다 하는 흔들기를 2~3번만 하고 쉽니다**
(평소에는 아주 느리게 살랑거리는 정도). 스프링은 충분히 감쇠돼 있어서 떨리거나 엔진처럼 진동하지 않고,
관절 각속도에도 상한(`TailSim.VMAX`)이 있습니다.
동작마다 꼬리 자세는 `animations.py`의 `tb`(밑동 각도), `tc`(말림), `tw`(흔들림 크기), `tf`(빠르기)로 정합니다.
일러스트 모양의 색상은 `catrig.py` 맨 위의 `C_BODY`, `C_STRIPE`, `C_EYE` 등으로 바꿉니다.

## 아이콘 차기는 실제 아이콘을 움직입니다

- 실행 중에만 바탕화면 "격자에 맞춤"을 꺼서 아이콘이 부드럽게 미끄러지게 합니다.
- 시작할 때 위치를 `icons_backup.json`에 저장하고, 종료하면 **위치와 격자 설정을 모두 원래대로** 되돌립니다.
- 작업 관리자로 강제 종료했다면, 다음에 고양이를 실행할 때 남은 백업으로 자동 복구합니다.
- 트레이 메뉴의 **아이콘 원래대로**로 실행 중에도 언제든 즉시 되돌릴 수 있습니다.
- 바탕화면 "자동 정렬"이 켜져 있으면 아이콘 차기는 자동으로 꺼집니다.
- 차인 아이콘은 다른 아이콘 위에 겹칠 수 있습니다 (복원하면 해결).

## 제한

- 주 모니터에서만 돌아다닙니다.
- 관리자 권한으로 실행된 창이나 전체화면 앱 위에서는 가려질 수 있습니다.

## 문서 (사용자 매뉴얼 · 기술 문서)

`docs/` 폴더에 움직이는 그림이 있는 문서 사이트(HTML·CSS·JS)가 있습니다. 설치 없이 `docs/index.html` 을 열면 됩니다 (일부 브라우저에서 글꼴·그림이 안 나오면 `python -m http.server 8800 --directory docs` 후 `http://localhost:8800`).

- `docs/manual.html` — 사용자 매뉴얼: 설치, 조작 연습장, 설정 연결(캘린더·소식·메일), 경비 경보 읽기, 알림 시뮬레이터, 개인정보, 문제 해결
- `docs/tech.html` — 기술 문서: 프로세스 구성, 실행 흐름, 프레임 루프, JSON 스키마, 그리기·행동·알림·경비 알고리즘, 재구현 순서, 상수 모음
- 코드를 고친 뒤 `python docs/build_docs.py` 를 실행하면 파일 수·줄 수·모듈 의존 그래프·행동 확률표가 코드에서 자동으로 다시 만들어지고, `docs/src/` 의 조각들이 `manual.html`·`tech.html` 로 합쳐집니다.
